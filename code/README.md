# 从公式到运行结果

本轮提供四个CPU教学实验，Python 3.10+，仅标准库，无需显卡、账号、联网下载模型或第三方训练框架。在项目根目录运行。

| 项目 | 命令 | 对应课程 | 验收 |
|---|---|---|---|
| 自动微分 | `python code/00-micrograd/main.py` | 0-4、2-0 | 梯度与有限差分一致，拟合损失低于1e-8 |
| 微型GPT | `python code/01-nanogpt/main.py --output code/01-nanogpt/runs/report.json` | 0-8、3-0 | 固定训练窗口loss下降，生成自编语法文本 |
| LoRA机制 | `python code/02-lora/main.py` | 5-6 | 底座不变，损失低于1e-6，合并误差低于1e-10 |
| RAG检索基线 | `python code/07-rag/main.py` | 10-0 | 检索/拒答6题与删除检查通过 |

微型GPT包含自己实现的标量反传、矩阵乘法、双头因果注意力、RMSNorm、FFN和优化器，没有调用torch/transformers。它刻意使用很小的维度与自编重复语法，以便普通CPU验证机制；不是已经完成真实语料上的nanoGPT训练或求职项目。

RAG项目默认摘录原始证据，不调用生成模型。应先测好检索，再接实际模型，另测生成忠实度、引用正确率与拒答；不要将摘录基线的通过率当LLM生成成绩。

后续升级路线：扩大并隔离语料 → 保存/恢复模型权重 → 独立验证集 → 矩阵化加速 → 真实SFT → 偏好对齐 → 部署测试。DPO、GRPO、真实大模型QLoRA和国产硬件实验仍属于后续建设。
