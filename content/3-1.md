## why

2-2 已经讲过位置编码的三大家族：sinusoidal（加在嵌入上）、RoPE（旋转 Q/K）、ALiBi（加线性偏置）。本单元把其中最重要的 RoPE **从"会用"推到"懂为什么"**：为什么旋转能编码位置？为什么点积天然只剩相对距离？这个性质对长上下文意味着什么——以及为什么 RoPE 模型一超出训练长度就"变傻"（外推失效），工业界又用什么手段把上下文从 4k 拉到 128k 甚至 2M。这是 3-5 长上下文配方的第一块砖，也是读任何现代 LLM 技术报告的必备背景。

## body

### 复数复习：旋转就是乘一个单位复数

2-2 只给了结论。这里从复数出发完整推一遍。把二维向量 \((x_1,x_2)\) 看作复数 \(z=x_1+ix_2\)。乘以单位复数 \(e^{im\theta}=\cos m\theta+i\sin m\theta\) 的效果：

\[
z' = e^{im\theta}\cdot z
\]

这正是把向量**逆时针旋转 \(m\theta\)**。所以"给位置 \(m\) 编码"在 2D 情形 = "把内容向量旋转 \(m\theta\)"，\(\theta\) 是一个固定的基础角。位置每加 1，多转一个 \(\theta\)——位置信息被编码成"转过的角度"，这就是 RoPE 的全部直觉。

### 相对性：三步推导

设 token 在位置 \(m\)，内容向量 \(q_m\)；另一个 token 在位置 \(n\)，内容向量 \(k_n\)。RoPE 施加后：

\[
\tilde q_m = R(m\theta)q,\qquad \tilde k_n = R(n\theta)k
\]

注意力分数是它们的内积：

\[
\langle \tilde q_m, \tilde k_n\rangle = (R(m\theta)q)^\top (R(n\theta)k) = q^\top R(m\theta)^\top R(n\theta) k
\]

旋转矩阵正交：\(R(m\theta)^\top=R(-m\theta)\)，且 \(R(-m\theta)R(n\theta)=R((n-m)\theta)\)。于是：

\[
\boxed{\;\langle \tilde q_m,\tilde k_n\rangle = q^\top R((n-m)\theta)\,k = \langle q, R((n-m)\theta)k\rangle\;}
\]

**点积只依赖相对位置 \(n-m\)，与绝对位置无关。** 三步里最关键的是第二步——旋转矩阵的正交性把两个绝对旋转"抵消"成一个相对旋转。这与 sinusoidal 的结论一致（2-2 说过：相对位置可线性表出），但 RoPE 是**在注意力分数内部**自然实现的，不依赖模型去学这个线性关系。

### 高维：每对维度一个频率

真实模型里 \(d=4096\)，不可能所有维度用同一个 \(\theta\)——那样位置稍大就转好多圈，远近位置全部混淆。RoPE 把向量按**维度对**分组，第 \(i\) 对用基础角：

\[
\theta_i = \text{base}^{-2i/d},\qquad i=0,1,\dots,d/2-1
\]

- \(i\) 小（\(\theta_i\) 大）：转得快——**高频维度**，编码细粒度的近距离差异（相邻 1 位也分得清），但稍远就转满圈、失去区分度；
- \(i\) 大（\(\theta_i\) 小）：转得慢——**低频维度**，覆盖长距离，但近处不敏感。

一组从快到慢的频率叠加，像钟表的时针/分针/秒针——不同粒度各管一段。base（默认 10000）控制频率的下降速率：base 越大，最高频与最低频的差距拉得越开，长距离表示能力越强（后面外推方案会用到）。

### 用二阶微分方程算出每个维度的"波长"

上面"高频/低频""盯不同粒度"的说法可以完全精确化。单独看第 \(i\) 个维度对：把该对的二维向量写成复数（沿用"复数复习"那节的记号），RoPE 施加后，它对注意力分数的贡献是 **相对距离 \(\Delta=n-m\) 的函数**：

\[
s_i(\Delta)=\operatorname{Re}\!\left[Q_i\bar K_i\,e^{i\Delta\theta_i}\right]=A_i\cos(\Delta\theta_i+\varphi_i)
\]

其中 \(A_i=\lvert Q_i\bar K_i\rvert\)、\(\varphi_i=\arg(Q_i\bar K_i)\) 全部由内容决定，与位置无关——**位置只出现在 \(\Delta\) 里**。现在把 \(\Delta\) 连续化，对相对距离**逐次求导**：

\[
\frac{d s_i}{d\Delta}=-A_i\theta_i\sin(\Delta\theta_i+\varphi_i),\qquad
\frac{d^{2} s_i}{d\Delta^{2}}=-A_i\theta_i^{2}\cos(\Delta\theta_i+\varphi_i)=-\theta_i^{2}\,s_i
\]

于是每一对维度的注意力贡献都满足**简谐振动方程**（二阶常系数线性微分方程）：

\[
\boxed{\;s_i''(\Delta)+\theta_i^{2}\,s_i(\Delta)=0\;}
\]

写成这个熟悉的形式，立刻读出两件事：

1. **角频率就是 \(\theta_i\)，波长（转满一圈所跨的 token 数）因此是**

\[
\lambda_i=\frac{2\pi}{\theta_i}=2\pi\cdot \mathrm{base}^{\,2i/d}
\]

代入真实数字就有手感了：取 \(d=4096\)、\(\mathrm{base}=10^{4}\)，最慢的一对（\(i=d/2-1\)，\(\theta_i\approx10^{-4}\)）波长 \(\lambda\approx2\pi\times10^{4}\approx6.3\times10^{4}\) 个 token；最快的一对（\(i=0\)，\(\theta_0=1\)）波长只有 \(2\pi\approx6.3\) 个 token。**钟表的三根指针从此有了确切换算**——这正是 YaRN 里"按波长给注意力分数加距离偏置"的那个波长 \(\lambda_i\) 的来源，不再是凭空的超参。
2. **二阶导就是曲率，度量这个维度对位置变化有多敏感**：\(\lvert s_i''\rvert=\theta_i^{2}\lvert s_i\rvert\)。高频维度（\(\theta_i\) 大）二阶导极大 ⇒ 注意力分数随位置剧烈摆动 ⇒ 能分辨相邻一位的差异；但也正因为摆得快，它最容易在训练长度之外跑进从未见过的相位区间——这就是下面"外推失效"的定量说法。

由此，把"某个维度有没有被训练覆盖"变成一个**可判定的不等式**。在长度 \(L_{\text{train}}\) 的训练里，第 \(i\) 对维度转过的完整周期数是 \(L_{\text{train}}/\lambda_i\)：

- **\(\lambda_i\le L_{\text{train}}\)（至少转满一圈）**：模型见过这一维的完整周期行为，其周期性已被学会 ⇒ 向更远距离外推相对可靠；
- **\(\lambda_i>L_{\text{train}}\)（连一圈都没转完）**：在训练范围内它只是一小段近似单调的弧 ⇒ 模型从没见过它的完整行为 ⇒ 一旦推理长度远超训练长度就进入未训练相位区，**这部分维度正是外推失效的直接来源**。

顺带把 \(\mathrm{base}\) 的作用也框进这张图。由 \(\lambda_i=2\pi\,\mathrm{base}^{2i/d}\) 可见：**调大 base 会把所有 \(i\ge1\) 的波长拉长**，把更多维度推入第二种情形。好处是它们留出了"没转满圈"的余量、不会在稍长的距离上就绕回去造成位置混淆；代价则是这些维度更难在短程训练中被充分学习（近距分辨率下降），也更需要靠长文本微调来补课。**base 的取值由此变成一道由波长分布决定的工程方程**：比较各个 \(\lambda_i\) 与 \(L_{\text{train}}\) 即可定量判断，而不再只是"取大一点试试"。

### 外推失效：训练时没转过的角度

RoPE 有个尖锐的阿喀琉斯之踵。训练长度 4k 意味着位置 \(m\in[0,4096)\) 的旋转角都见过；推理时来一个 8k 的序列，位置 4096~8192 的旋转角是**模型没见过的**——尤其高频维度，\(\theta_0\times 8000\) 早就超出训练分布，注意力分数进入未训练区域，输出质量断崖式下跌。这就是**长度外推失效**：不微调直接喂长文本，模型的表现比随机稍好但远低于短文本。

三种主流解法（按"要不要微调"分）：

**1. 位置插值（PI）**——Chen et al. 2023。最直接：把位置 \(m\) 缩放成 \(m\cdot L_{\text{train}}/L_{\text{test}}\)，等价于把所有旋转角线性压回训练见过的范围。好处是几乎无损地短上下文性能、微调很快收敛；坏处是高频维度被"压扁"，细粒度位置分辨率下降。

**2. NTK-aware / YaRN**——Peng et al. 2023。观察：外推失效的根源是高频维度转太快、低频维度根本没转够。PI 把所有维度一起压，误伤了高频。NTK-aware 的做法是不均匀缩放：**高频少压、低频多压**——对 base 本身做插值（base' = base·s^{d/(d-2)}），让频率谱按维度位置渐变。YaRN 在此之上再加两步：按波长给注意力分数加温和的距离偏置（把没见过的远距离"接"进分布）、对缩放后的表示做温度调整。YaRN 是 2023~2024 年把 4k→32k/128k 的事实标准之一，且几乎不损短文本。

**3. ALiBi 式的外推**——Press et al. 2021。ALiBi 加的是线性距离偏置，训练时没见过更远距离也"天然"延续（偏置公式与长度无关），这是它当年最大的卖点；缺点是绝对位置表示能力弱、且对 RoPE 生态（几乎所有开源模型）不兼容。今天的主流仍是 RoPE + 插值微调，ALiBi 主要用于特定研究场景。

### base 的选择：长上下文的第一颗螺丝

不微调也能改善一点的办法：**训练时就把 base 设大**。LLaMA-1 用 10000，后来做长上下文的模型普遍抬到 500000 甚至更高（LLaMA-3 用 500000）。base 越大，同样位置下低频维度"转得更慢"、高频维度"转得更慢"，全部维度都在训练长度内保持"没转满圈"的状态，为外推留出余量。代价是短距离分辨率略降。选 base 本质是在"短程精细"与"长程余量"之间选工作点。

### 一个统一的判断框架

遇到任何位置编码/外推方案，问三个问题：

1. **相对性怎么实现的？** 加在嵌入上（sinusoidal，靠模型学）/ 旋转 Q·K（RoPE，结构保证）/ 加偏置（ALiBi，结构保证）。
2. **外推靠什么延续？** 插值（把没见过压回见过）/ 改频率谱（让训练分布更耐外推）/ 公式天然外推（ALiBi）。
3. **代价落在哪？** 高频分辨率（PI）/ 短文本质量（几乎所有方法都略损）/ 需要微调数据与算力（PI/YaRN 都要少量长文本退火）。

## ex

**练习 1（对应退出标准 1）**
写出 RoPE 在 2D 情形对 q、k 的变换，并用旋转矩阵的正交性三步推出点积只依赖 \(n-m\)。

%%%

**参考答案：**
\(\tilde q_m=R(m\theta)q,\ \tilde k_n=R(n\theta)k\)，其中 \(R(\alpha)=\begin{pmatrix}\cos\alpha&-\sin\alpha\\\sin\alpha&\cos\alpha\end{pmatrix}\)。点积 \(\tilde q_m^\top\tilde k_n=q^\top R(m\theta)^\top R(n\theta)k\)；正交性给 \(R(m\theta)^\top=R(-m\theta)\)；旋转复合律给 \(R(-m\theta)R(n\theta)=R((n-m)\theta)\)。故点积 \(=q^\top R((n-m)\theta)k\)，只剩相对距离。

**练习 2（对应退出标准 2）**
解释 RoPE 中"高频维度 vs 低频维度"的分工，并说明 base=10000 与 base=500000 的差别落在哪。

%%%

**参考答案：**
\(\theta_i=\text{base}^{-2i/d}\)：小 \(i\)（大 \(\theta_i\)）转得快，是高频维度，分辨近距离差异但远处转满圈失效；大 \(i\)（小 \(\theta_i\)）转得慢，是低频维度，覆盖长距离但近处不敏感。base 控制频率下降速率：base 越大整体转得越慢，同样位置下各维度离"转满圈"更远，为外推留余量，但短程分辨率略降。

**练习 3（对应退出标准 3）**
什么是长度外推失效？用"训练时没转过的角度"解释 RoPE 模型为什么超长度就变傻。

%%%

**参考答案：**
训练长度 \(L_{\text{train}}\) 内，模型见过位置 \(0\sim L_{\text{train}}\) 的全部旋转角；超过后，新位置的旋转角（尤其高频维度的 \(m\theta_0\)）落在训练分布之外，注意力分数进入未训练区域，softmax 分布失真，输出断崖式下跌。本质：RoPE 把位置编码成角度，角度外推不是平滑的。

**练习 4（对应退出标准 4）**
PI（位置插值）与 NTK-aware/YaRN 的核心区别是什么？各自的代价落在哪？

%%%

**参考答案：**
PI 把所有位置线性压回训练范围（\(m\to m\cdot L_{\text{train}}/L_{\text{test}}\)），相当于所有维度一起压——简单、微调快，但高频维度被压扁、细粒度分辨率下降。NTK-aware 识别出"高频不许压、低频才该压"，对 base 做非均匀缩放，YaRN 再加距离偏置与温度调整——短文本几乎无损，但方案更重。共同代价：都需要少量长文本微调与对应算力。

**练习 5（对应退出标准 5）**
给一个 4k 训练的 LLaMA 式模型，要拉到 32k 上下文，按本单元框架列出三个问题与对应答案。

%%%

**参考答案：**
① 相对性实现：RoPE（旋转 Q/K，结构保证）→ 外推要处理的是角度外推。② 外推手段：YaRN 式非均匀频率缩放 + 少量长文本退火微调；或先把 base 抬到 50 万再训练。③ 代价：短文本质量略损（需在短任务上回归测试）、微调数据与算力、评测要用长文本集验证（3-5 的 RULER 等）。

**练习 6（对应退出标准 6）**
RoPE 第 \(i\) 对维度的注意力贡献可写成 \(s_i(\Delta)=A_i\cos(\Delta\theta_i+\varphi_i)\)，其中 \(\Delta=n-m\)，\(\theta_i=\text{base}^{-2i/d}\)。
(a) 对 \(\Delta\) 求二阶导，证明它满足 \(s_i''+\theta_i^2 s_i=0\)，并由此写出波长 \(\lambda_i\) 的表达式。
(b) 取 \(d=4096\)、\(\text{base}=10^4\)，估算最慢一对（\(i=d/2-1\)）与最快一对（\(i=0\)）的波长，说明为什么它们分别对应"粗粒度长距"与"细粒度近距"。
(c) 用 \(\lambda_i\) 与 \(L_{\text{train}}\) 的大小关系，给出"某个维度是否被训练充分覆盖"的判据；据此说明调大 base 的好处与代价。

%%%

**参考答案：**
(a) \(s_i'=-A_i\theta_i\sin(\Delta\theta_i+\varphi_i)\)，\(s_i''=-A_i\theta_i^2\cos(\Delta\theta_i+\varphi_i)=-\theta_i^2 s_i\)，即 \(s_i''+\theta_i^2s_i=0\)（简谐振动方程），角频率即 \(\theta_i\)，故 \(\lambda_i=2\pi/\theta_i=2\pi\cdot\text{base}^{2i/d}\)。二阶导还给出敏感度：\(|s_i''|=\theta_i^2|s_i|\)，高频维度对位置变化极敏感。
(b) 最慢一对 \(i=2047\)：\(\theta\approx10^{-4}\)，\(\lambda\approx2\pi\times10^4\approx6.3\times10^4\) token（波长六万多，只在极长距离上才完成一圈 ⇒ 管长距粗粒度）。最快一对 \(i=0\)：\(\theta_0=1\)，\(\lambda=2\pi\approx6.3\) token（每 6 个 token 就绕一圈 ⇒ 只分得清极近的距离，远了就混淆）。这正是"三根指针"的定量版本，也是 YaRN 按波长加偏置时那个 \(\lambda_i\) 的来源。
(c) 判据：\(\lambda_i\le L_{\text{train}}\)（转满至少一圈）⇒ 见过完整周期行为，较可靠；\(\lambda_i>L_{\text{train}}\)（连一圈都没转完）⇒ 训练范围内只是一小段近似单调的弧，推理长度超出后进入未训练相位区 ⇒ 这是外推失效的直接来源。调大 base 会拉长所有 \(i\ge1\) 的波长：好处是留出"没转满圈"的余量、近距之外不易位置混淆；代价是更多维度在短程训练中难以被充分学习（近距分辨率下降），且更依赖长文本微调补课。
