A 类MoE 路由：坍缩、均衡与 token dropping
每步 batch 有 12 个 token 进入路由层。专家分数 = token 亲和度 + 专家熟练度 w——熟练度随分到的 token 增长（数据多的专家训得更好），这就是坍缩的正反馈：把 α 拖到 0 连播几步，看明星专家如何通吃、其余专家饿死（虚线是各专家的熟练度 w）。α=0.02 是 Switch Transformer 推荐的 10⁻² 量级：辅助损失把 w 拉回均值，负载恢复健康。柱子是路由器的头号选择（容量裁决前）；红色容量线是硬保险——超载的 token 分量被丢弃、走残差旁路，坍缩时丢弃量会暴涨。top-k 越大每个 token 的 MoE 计算越贵，但路由更稳。
