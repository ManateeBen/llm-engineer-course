## why

6-0 的 PPO 管线里最贵、最脆的两块是 critic（又一个 16Ψ 模型）和奖励模型（偏好数据的瓶颈、reward hacking 的温床）。对**答案可自动验证**的领域——数学题有标准答案、代码能跑单测、格式能正则检查——奖励根本不需要学习，写个 checker 就行（**RLVR：Reinforcement Learning with Verifiable Rewards**）。DeepSeekMath 的 GRPO 顺势砍掉 critic：同一道题采样一组回答，用**组内相对排名**当优势。这一刀改变了历史：2025 年的推理模型（DeepSeek-R1、o1 类）全是"基座 + GRPO/RLVR"训出来的，长思维链、自我验证、"aha moment"都是纯 RL 的涌现产物。本单元把 GRPO 的目标、变体、以及与 6-6 系统工程的接口算清楚。

## body

### 1 组内相对优势：砍掉 critic 的那一刀

PPO 的优势 \(\hat A_t=R_t-V(s_t)\) 需要一个 value 模型估基线。GRPO 的观察：**同一 prompt 采 \(G\) 个回答，它们的平均奖励就是现成的基线**：

\[
\hat A_i\;=\;\frac{r_i-\mathrm{mean}(\{r_1,\dots,r_G\})}{\mathrm{std}(\{r_1,\dots,r_G\})},
\qquad i=1,\dots,G
\tag{6.2.1}
\]

策略目标与 PPO 同构（clip + KL 正则）：

\[
J_{\text{GRPO}}(\theta)=\mathbb{E}\Bigl[\frac{1}{G}\sum_{i=1}^G\frac{1}{|y_i|}\sum_{t=1}^{|y_i|}\min\bigl(\rho_{i,t}\hat A_i,\ \mathrm{clip}(\rho_{i,t},1\pm\epsilon)\hat A_i\bigr)\Bigr]-\beta\,\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})
\tag{6.2.2}
\]

其中 \(\rho_{i,t}=\pi_\theta(y_{i,t}|s_{i,t})/\pi_{\text{old}}(y_{i,t}|s_{i,t})\)。

**为什么组内均值是合法基线**：\(\mathbb{E}_{r\sim\text{组内}}[r_i-\bar r]=0\)——组内中心化让优势零均值（PPO 里这是 value 网络的活）；除以 std 让不同难度 prompt 的优势尺度一致（难题奖励方差大，不归一化的话梯度被难题 prompt 主导）。**统计实质：用蒙特卡洛组估计代替学习的价值函数**——省一个模型，代价是每组要多采 \(G\) 个回答（算力换模型）。

### 2 RLVR：可验证奖励的三类与各自的坑

| 奖励类型 | 实现 | 坑 |
|---|---|---|
| **数学** | 最终答案 exact match（LaTeX 归一化后比对） | 答案对但过程错也得分（过程奖励 PRM 补）；格式错误误判 |
| **代码** | 沙箱跑单测，pass 率即奖励 | 沙箱逃逸安全（6-5 的系统防御）、超时、依赖环境漂移 |
| **格式/规则** | 正则/结构校验（如 thinking 标签） | 太死板会抑制有用的创造性表达 |

**没有 RM 就没有 reward hacking 的主入口**——这是 RLVR 相对 6-0 最大的安全性增益。但奖励设计错误会变成另一种黑客：奖励"答案出现概率"而不"答案正确"，模型会学会反复猜同一个数；奖励"用了特定关键词"，模型学会堆关键词。**RLVR 的第一纪律：奖励函数要审计到"模型能刷它的每一条路径"**（与 6-3 的过优化同源，只是敌人从 RM 变成了 checker 漏洞）。

### 3 两个 2025 年的关键修正：Dr. GRPO 与 DAPO

**Dr. GRPO**（Liu et al. 2025）指出（6.2.1）的 std 归一化引入两个偏置：

- **难度偏置**：简单题（全对或全错，std≈0）归一化后优势被放大，模型反复刷简单题；
- **长度偏置**：错误回答往往更长（模型"想太多想歪"），按 \(|y_i|\) 平均 + std 归一化会系统性地改变长短回答的梯度权重——Dr. GRPO 去掉 std 归一化、保留长度平均，数学题上收敛更稳。

**DAPO**（Yu et al. 2025，字节 Seed 开源系统）四项工业级技术：① **Clip-Higher**：解耦上下裁剪阈值（\(\epsilon_{\text{low}}=0.2,\epsilon_{\text{high}}=0.28\)），给低概率 token 的探索留空间——长 CoT 里大量低概率 token 被标准 PPO clip 冻住，熵坍缩；② **Dynamic Sampling**：过滤掉组内全对/全错的 prompt（优势全 0 无梯度），保证每批有效梯度；③ **Token-Level Loss**：按样本总 token 归一化而非按 prompt 数，防长回答主导；④ **Overlong Reward Shaping**：超长回答给软惩罚（长度超限逐步扣分），防"想不完不许结束"的复读。

### 4 DeepSeek-R1：纯 RL 涌现出了什么

R1 报告的核心发现（复现自 2025-01 起多家验证的现象学）：

1. **R1-Zero**（基座直接 GRPO，无 SFT 冷启动）：奖励只给"答案正确 + 格式合规"。训练中模型自发出现**变长的思考**（自发的"等等，让我重新想"）、**自我验证**（"验算一下：…对上了"）、**反思**。这些能力没有写在奖励里——是"多试几种思路再提交"在可验证奖励下更可能答对，被 RL 放大的结果。
2. **纯 RL 的代价**：可读性差、语言混杂（中英混杂思考）、格式不稳。解法是 R1 正式版管线：冷启动 SFT（几千条长 CoT）→ 面向推理的 RL → 拒绝采样生成新 SFT 数据（6-4 的 RFT）→ 全场景 RL（有用性+安全+推理）。
3. **蒸馏的启示**：R1 报告里用 R1 生成的数据蒸馏 Qwen/Llama 小模型，小模型推理能力大幅提升——**推理能力可以"注入"，不只"训练出来"**（6-4 的边界）。

**对基础设施的直接后果**（6-6 的口径）：RLVR 的 rollout 是**长生成**（单条 8K~32K token 思考），比 SFT 时代的 batch 重几倍；生成速度与训练速度失配更严重（rollout 墙钟远长于一步训练）；奖励计算要跑沙箱（代码单测）——**RL 系统 = 生成集群 + 训练集群 + 沙箱集群三类资源的编排**。

### 5 GRPO vs PPO：一张对比表

| 维度 | PPO（6-0） | GRPO |
|---|---|---|
| 基线来源 | critic \(V_\phi\) 学习 | 组内均值/std，无模型 |
| 模型显存 | ≈36Ψ | actor 16Ψ + ref 2Ψ ≈ **18Ψ** |
| 每 prompt 采样数 | 1（on-policy 流式） | \(G\)（典型 16~64） |
| 奖励来源 | RM（可被 hack） | verifier（数学/代码/格式） |
| 适用域 | 开放域人类偏好 | 可验证域 + 推理 |
| 超参敏感度 | critic 训练稳定性 | std 归一化偏置、clip 阈值 |

**决策口径**：开放域风格/安全对齐用 6-1 的 DPO 系（更便宜）或 PPO；数学/代码/推理能力提升用 GRPO/RLVR；两者常混合（推理 RL 完成后再跑一轮偏好对齐）。

## ex

**练习 1（对应退出标准 1）**
一组 8 个回答的奖励 \(\{0,0,1,0,1,1,0,1\}\)。按（6.2.1）算每个回答的优势（用总体标准差），并解释为什么"全对组"和"全错组"在 GRPO 里没有梯度。

**参考答案：**
mean \(=4/8=0.5\)，std \(=\sqrt{\frac{8\times0.25}{8}}=0.5\)。优势：\(1\to(1-0.5)/0.5=+1\)，\(0\to(0-0.5)/0.5=-1\)。全对组：所有 \(r_i=1\) ⇒ 差全 0 ⇒ \(\hat A_i=0\)，目标里整组无梯度——GRPO 只在**组内有区分度**时学习（"比同组其他尝试好/差"），这正是 DAPO 的 dynamic sampling 要过滤掉全对/全错 prompt 的原因：它们白占采样算力。

**练习 2（对应退出标准 2）**
证明组内中心化使 \(\mathbb{E}[\hat A_i]=0\)（在组内奖励分布下），并说明除以 std 如何缓解"难题主导梯度"。

**参考答案：**
\(\mathbb{E}[r_i-\bar r]=0\) 显然（样本均值是均值的无偏估计，单个样本减样本均值的期望为 0）。难题组：奖励方差大（有的路径对有的错），不除 std 时优势绝对值大，batch 内梯度被难题 prompt 主导；除以 std 后每组优势尺度统一为 ±1 量级，**每个 prompt 无论难易对梯度的贡献同量级**——代价见 Dr. GRPO：std 本身在偏态分布（几乎全错）里是噪声放大器。

**练习 3（对应退出标准 3）**
GRPO 相比 PPO 省掉 critic（16Ψ）。13B 模型 BF16：算两者显存差额；再算每步采样成本差异：PPO 每 prompt 采 1 条，GRPO 采 32 条、平均 2K token/条。给"GRPO 用采样算力换 critic 显存"的定量结论（按 8-6 口径）。

**参考答案：**
显存：critic \(16\Psi=16\times13\times10^9\) 参数对应 BF16 全量 ≈ 156 GB（权重 26 + 梯度 26 + Adam 104）；GRPO 省这 156 GB，只多留 ref 26 GB ⇒ 净省 ≈ 130 GB（半台 8 卡机）。采样：PPO 每 prompt 1×2K=2K token；GRPO 32×2K=64K token/ prompt——**采样量 ×32**。换算：13B 模型每 token 前向算力 \(2N=2.6\times10^{10}\) FLOPs；64K token ≈ \(1.7\times10^{15}\) FLOPs ≈ 2.2 PFLOP 量级/ prompt，在 2.2 PFLOPS 卡上理论 1 s/prompt 的纯生成算力（实际含调度开销 3~5 倍）。结论：**critic 的 156 GB 显存 ≈ 每 prompt 多 32 倍生成**——显存便宜（可 ZeRO 分摊）而生成贵（纯增量），所以实践中 PPO 派在开放域仍有一席之地，但可验证域里"省心"压过"省钱"。

**练习 4（对应退出标准 4）**
DAPO 的 Clip-Higher：\(\epsilon_{\text{low}}=0.2,\epsilon_{\text{high}}=0.28\)。解释为什么长 CoT 训练中"低概率 token 被标准 clip 冻住"会导致熵坍缩，以及抬高上界为什么是对症的。

**参考答案：**
长 CoT 里模型探索的是低概率推理路径，\(\pi_{\text{old}}\) 很小，一次成功的更新把 \(\pi_\theta/\pi_{\text{old}}\) 推过 \(1+\epsilon\) 后梯度归零（6-0 练习 3 的机制）——**一旦某条低概率思路偶然成功并被强化，再进一步强化就被 clip 挡住，其他低概率思路再也没有机会被探索**：熵单调下降，输出坍缩到少数几套路子。Clip-Higher 把上界抬到 0.28（对 \(\hat A>0\) 分支），给"成功但罕见"的思路留出继续上升的空间，维持探索多样性。**本质：clip 的对称性假设了奖励信号的稠密性，长 CoT 里奖励极稀疏（整条 8K token 只有终局 ±1），不对称 clip 是在补偿稀疏性。**

**练习 5（对应退出标准 5）**
某数学 RL 用"答案包含正确答案字符串"做奖励。列出三条模型可能学到的"刷分捷径"，各给一条奖励函数修正。

**参考答案：**
① 把 1~100 全列一遍（"答案是 42"必然包含）——修正：要求**终止标记前只出现一个**最终答案框，且多余内容扣格式分；② 答案对但过程胡说（"显然答案是 42"蒙对）——修正：加过程抽检（PRM 或过程格式约束），或提高题目难度使蒙对率下降；③ 复读训练集里见过的题（记忆泛化）——修正：训练集/测试集去重（4-0 的 MinHash），污染检测（7-1）。**原则：奖励函数要当作被攻击面来设计——假设模型会找到任何"满足 checker 但不满足意图"的路径（与 6-3 的 RM 过优化同构，敌人从学出来的 RM 变成手写的 checker）。**

**练习 6（对应退出标准 6）**
R1-Zero 的涌现（自我验证、反思）没有写在奖励里，为什么 RL 能"无中生有"？给出严格解释（提示：从策略梯度的期望看），并指出涌现不发生的条件。

**参考答案：**
严格解释：策略梯度 \(\nabla J=\mathbb{E}[r_t\nabla\log\pi]\) 只加权**高奖励轨迹**。若基座模型的策略分布里本来就存在（小概率）"先验验算再提交"的轨迹（预训练语料里有大量"检查一下"模式），这类轨迹在可验证奖励下**统计上**答对率更高，被持续放大——**不是 RL 发明了新能力，是 RL 把预训练里的低频有效模式放大成高频**。不发生的条件：① 基座策略分布里该模式的概率近似 0（RL 放大不了没采到的东西——纯探索问题）；② 奖励对该模式无区分度（该模式答对率不高于均值）；③ 组内优势被其他因素主导（如 Dr. GRPO 的长度偏置压过长思考）。**工程含义：RL 的能力上限由基座分布覆盖度决定——选基座比调 RL 超参更根本。**
