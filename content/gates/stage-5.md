## Q1 [5-0]
从 SGD 理论看，为什么学习率必须衰减？恒定学习率下 loss 会停在哪里？
- A. 衰减是为了加快初期收敛；恒定学习率下 loss 会直接 NaN
- B. 高学习率下参数在最优解附近以半径 ∝η 的球里随机游走，loss 停在由 η 决定的平台上；衰减收缩游走球才能沉到谷底
- C. 衰减是为了让 batch 更大；恒定学习率下 batch 自动变小
- D. 衰减与理论无关，纯属工程经验
答案：B
解析：SGD 迭代 = 梯度期望 + 与 η 成正比的噪声。loss 接近最优时梯度变小但噪声半径不缩，参数在半径 ∝η 的球里持续随机游走，loss 停平台。衰减 η 逐步收缩游走球，参数才沉到谷底。理论最优（强凸）η_t∝1/t；非凸实践解为"高位探索+末段快速收缩"。

## Q2 [5-0]
cosine 调度相对 linear 衰减的改进在于？
- A. cosine 末段下降更快，所以最终 loss 一定最低
- B. cosine 两头变化慢、中段下降快，把最陡下降放在 loss 下降最快的中段
- C. cosine 不需要 warmup
- D. cosine 比 linear 计算更便宜
答案：B
解析：linear 前段几乎不降、末段才沉；cosine 公式 η_t=η_min+½η_max(1+cos(πt/T))，两头慢中段快，把下降能力集中在 loss 下降最快的中段。Chinchilla 用的就是 warmup+cosine 衰减到 10% 峰值收尾。

## Q3 [5-0]
WSD（Warmup-Stable-Decay）相比 cosine 的核心工程红利是？
- A. WSD 最终 loss 严格低于 cosine
- B. 稳定期任意 checkpoint 接一段 decay 都接近全程最优——随时可停、decay 可复用
- C. WSD 不需要学习率预热
- D. WSD 只能用于小模型
答案：B
解析：Hägele 2024 证明 decay 段等价于对稳定期 checkpoints 的隐式平均，故稳定期任意点退出接 decay 都接近全程最优。红利：① 随时可停（数据泄露/硬件到期不破产）② decay 可复用（hitchhiker，用小算力搭车）③ 中期不怕"loss 平了"。MiniCPM 首次系统使用，Llama-3/Qwen 等沿用。

## Q4 [5-0]
关于衰减段长度与末值，下列哪项符合正文？
- A. decay 占全程 2% 以下即可拿到大部分收益
- B. decay 占全程 5%~10% 收益最佳，低于 2% 固化不充分；cosine 末值常用峰值 10%，WSD decay 末端应更低（1%~3% 或归零）
- C. WSD 末值应设为峰值 50% 以避免过拟合
- D. cosine 与 WSD 的末值都应设为 0
答案：B
解析：MiniCPM 及后续报告显示 decay 占 5%~10% 最佳，<2% 固化不充分。cosine 语境 Chinchilla 用峰值 10%；WSD 语境 decay 末端应更低（1%~3% 或归零），否则"退火不充分"最终 loss 明显偏高。

## Q5 [5-1]
有效 batch 的正确换算关系是？
- A. batch_eff = micro_batch × grad_accum
- B. batch_eff = micro_batch × grad_accum × data_parallel
- C. batch_eff = micro_batch + grad_accum + data_parallel
- D. batch_eff = grad_accum × data_parallel
答案：B
解析：batch_eff = micro_batch × grad_accum × data_parallel。micro-batch 由单卡显存决定；梯度累积把一次大 batch 的梯度平均拆成多次小 batch 前向再平均，优化动态接近大 batch 但不增加峰值显存。

## Q6 [5-1]
为什么序列长度是最贵的量？
- A. 它只影响数据读取速度，不影响显存
- B. 注意力的 KV cache 与 QKᵀ 相似度矩阵是 L×L，显存 𝒪(L²)、算力 𝒪(L²d)，且固定显存下 micro-batch 上限反比于 L
- C. 序列长度翻倍，显存也正好翻倍
- D. 长序列能无条件提升有效 token 密度
答案：B
解析：注意力段随 L 超线性增长（平方），固定显存下 micro-batch 上限反比于 L（注意力主导段 1/L²），所以长序列被迫砍 micro-batch 再用 accum 补有效 batch。误区"序列翻倍显存翻倍"是错的——平方关系下翻 4 倍。

## Q7 [5-1]
学习率随 batch 的线性缩放规则及其限制是？
- A. batch 翻倍、学习率减半，无上限
- B. 有效 batch 乘 k、学习率可乘 k，但上限由临界 batch size 决定——超过后继续加 batch 必须同步降学习率
- C. 学习率与 batch 完全无关
- D. 只有 batch 小于 4 时才需调学习率
答案：B
解析：Goyal 2017 等验证有效 batch 乘 k、学习率可乘 k（大 batch 梯度噪声更小可迈大步），前提是未超临界 batch size；超过后噪声近最优，继续加 batch 须同步降学习率否则发散。这正是 2-4 临界 batch size 的落点。

## Q8 [5-2]
大模型训练几乎必然出现 spike（孤立尖峰）的机制是？
- A. 学习率永远设错了
- B. 参数空间更尖 + 长尾离群样本梯度范数可达均值几十倍，高学习率稳定期一脚踢出吸引盆
- C. 数据量永远不够
- D. 只有不用 RMSNorm 才会 spike
答案：B
解析：大模型参数空间曲率更大，离群 batch 梯度范数可达均值几十倍，高学习率下把参数踢出吸引盆即 spike。多数自恢复，但可能连锁崩成 divergence。缓解：RMSNorm（去可学习 scale）、SwiGLU、DeepNorm——100B+ 稳定训练的前提。

## Q9 [5-2]
loss 曲线的"静默不收敛"（⑤）为何最危险？正确对策是？
- A. 它不影响训练，无需处理
- B. loss 数字正常但下游能力为零（数据 bug/mask 错/并行丢梯度），唯一防线是每 checkpoint 跑下游探针
- C. 它只出现在小模型上
- D. 对策是加大学习率
答案：B
解析：⑤ 类异常数字好看却能力为零，因为数据管道 bug、因果掩码写错、并行通信丢梯度等。loss 是好训练的必要条件非充分条件，唯一拦截手段是高频轻量能力探针，分数零立即停。

## Q10 [5-2]
检测到 spike 后，自动回滚流程的正确做法是？
- A. 立即从头重训
- B. 停训→加载最近干净 checkpoint→跳过坏 batch 区间→仍 spike 则降 LR×0.5 重试→超 k 次告警
- C. 忽略，spike 都会自愈
- D. 把学习率调高一倍强行压住
答案：B
解析：GPT-3 重训 7 次会破产；正确是回滚+跳 batch 保留已学知识只丢坏部分，分钟级恢复。超过临界重试次数才人工介入。跳 batch 合理因已学知识在 checkpoint 里。

## Q11 [5-3]
持续预训练（CPT）引发灾难性遗忘的权重空间机制是？
- A. 领域数据自动增强通用能力
- B. 所有能力编码在同一组权重，领域梯度沿"降领域 loss"方向走，几乎必然同时抬高通用 loss
- C. 遗忘只发生在指令遵循，与权重无关
- D. 加领域数据越多忘得越少
答案：B
解析：Goodfellow 2013 奠基、Chen 2025 在 LLM 规模量化：能力同权重编码，领域梯度方向通常同时抬高通用 loss，长步数下通用指标单调下滑。遗忘不均匀——指令/长尾知识最脆弱，底层语言最顽固。

## Q12 [5-3]
标准 CPT 配方"三道刹车"不包括下列哪项？
- A. 数据混合：领域 70~90% + 通用 replay 10~30%
- B. 学习率退火：从原峰值 10~30% 起步快速退火
- C. 纯领域数据（replay 0%）以求最大领域增益
- D. 顺序与步数控制：先 replay 巩固或全程混合+退火，用探针早停
答案：C
解析：纯领域数据必严重遗忘（replay 0% 时通用分数自由落体），需混 10~30% 通用 replay 直接给优化器"复习"通用分布。高学习率重砸会大幅遗忘，应退火；步数越多忘越多应早停。

## Q13 [5-3]
若原模型已 SFT/RLHF，做纯 CPT 会怎样？应如何补救？
- A. 对齐会自动保留，无需处理
- B. 纯 CPT 会冲掉对齐（对齐被遗忘）；需在 replay 混入指令数据或 CPT 后轻量 SFT 补回
- C. 纯 CPT 会增强对齐
- D. 只需加大领域数据比例
答案：B
解析：已对齐模型纯 CPT 会冲掉对齐（"对齐税"反向版）。对策：replay 混入指令/对话数据，或 CPT 后做一轮轻量 SFT 把对齐补回。这是"指令保持 CPT"的关键额外注意点。

## Q14 [5-4]
训练监控的三层金字塔从底到顶是？
- A. 能力层 → 动态层 → 硬件层
- B. 硬件层（GPU/显存/带宽/掉卡）→ 训练动态层（loss/grad norm/吞吐/序列分布）→ 能力层（下游探针）
- C. 动态层 → 硬件层 → 能力层
- D. 只有 loss 曲线一层
答案：B
解析：硬件层是"训练在不在转"的底盘信号（利用率周期掉 0=瓶颈/通信挂死、显存慢爬=泄漏）；动态层是"健不健康"（grad norm 先于 spike、吞吐趋势、序列分布异常）；能力层是对付静默不收敛的探针。

## Q15 [5-4]
可复现性三档中，对外交付报告应达到哪一档？何时开/关确定性算子？
- A. 第一档逐位相同；生产训练也应常开
- B. 第三档"可解释可复现"（完整报告，达 Show Your Work 规范）；调试期开确定性锁 bug，生产训练关它以换吞吐（代价 -5~15%）
- C. 只需同机复现即可交付论文
- D. 确定性算子永远不能关
答案：B
解析：三档：同机逐位、跨机噪声带内一致、可解释可复现（Dodge 2019 Show Your Work）。对外交付应达第三档。确定性算子关闭非确定性加速会拖慢 5~15% 吞吐，故调试期开、生产训练关——强求逐位无必要且浪费算力。
