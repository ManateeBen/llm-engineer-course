## Q1 [6-0]
RLHF 三阶段管线的正确顺序与各自数据形态是？
- A. 先 RL 再 SFT 再 RM
- B. SFT（专家演示，单条）→ RM（成对偏好排序）→ RL（模型自身采样 + RM 打分）
- C. 直接 RL，不需要 SFT
- D. RM → SFT → RL
答案：B
解析：信息形态逐级转换：人类能 cheap 地给排序但不能 cheap 地写最好答案，RM 把稀疏排序压成稠密函数，RL 再用函数做全局优化。SFT 冷启动让模型先进入"像样回答"区域，否则 RM 在垃圾分布上训练。

## Q3 [6-0]
RLHF 四个模型的显存账（BF16，参数 Ψ）约为？

## Q4 [6-1]
DPO 能绕开奖励模型的关键一步是？
- A. 用了更大的模型
- B. KL 正则最优策略有闭式解，反解出奖励后用策略自身的 log-ratio 表示，代入 Bradley-Terry 时配分函数 Z(x) 在 chosen/rejected 差分中精确相消
- C. 不用参考模型
- D. 用在线采样代替 RM
答案：B
解析：变分法给 π*∝π_ref·exp(r/β)；反解 r=βlog(π/π_ref)+βlogZ；BT 概率只依赖奖励差，同一 prompt 下 Z(x) 相同 ⇒ 相消 ⇒ 隐式奖励 = log-ratio。DPO 仍需 ref（ORPO/SimPO 才去掉 ref）。

## Q5 [6-1]
DPO 训练中 chosen 与 rejected 的对数概率同时下降、但差距在拉大。这个现象叫？如何处置？
- A. 正常现象，不用管
- B. 似然位移（likelihood displacement）——监控绝对 logprob，加 SFT 混合损失或换 IPO
- C. 奖励黑客，加 KL
- D. 数据污染，重洗数据
答案：B
解析：DPO 只约束相对比率，不约束 chosen 的绝对概率。模型可靠"压低 rejected 更狠"降损失，整体概率质量缩水伤多样性。IPO 把目标 log-ratio 收敛到固定值而非无穷大，是对症药。

## Q6 [6-2]
GRPO 去掉 critic 的机制是？
- A. 用 RM 代替 critic
- B. 同一 prompt 采 G 个回答，组内均值当基线、组内 std 归一化当尺度：Â_i=(r_i−mean)/std
- C. 不要基线
- D. 用 SFT 模型当 critic
答案：B
解析：组内中心化使 E[Â]=0（基线的活），std 归一化统一各 prompt 的梯度尺度。全对/全错组 std=0、Â 全零无梯度——DAPO 的 dynamic sampling 过滤它们。代价：每 prompt 采 G 个（典型 16~64），用采样算力换一个价值网络。

## Q7 [6-2]
RLVR 中"奖励模型不存在所以没有奖励黑客"这个说法？
- A. 完全正确
- B. 错——checker 本身会被 hack（如"把 1~100 全列一遍"必然包含正确答案），奖励函数要当作攻击面审计
- C. 只有 RM 能被 hack
- D. 与训练数据无关
答案：B
解析：RLVR 消掉了"学出来的 RM"这个 hack 入口，但手写 checker 有漏洞（答案框不唯一、过程错但蒙对、复读训练题）。设计纪律：假设模型会找到任何"满足 checker 但不满足意图"的路径。

## Q8 [6-2]
Dr. GRPO 指出的 std 归一化偏置是？
- A. 偏置不存在
- B. 难度偏置（简单题 std≈0 被放大）与长度偏置（错误回答更长，归一化改变长短样本的梯度权重）——Dr. GRPO 去掉 std 归一化
- C. 只影响速度不影响质量
- D. 需要加 std
答案：B
解析：组内奖励偏态（几乎全错）时 std 是噪声放大器；按 token 平均 + std 归一会系统性地惩罚长回答。DAPO 的 Token-Level Loss 与 Overlong Shaping 治的是同一族问题。

## Q9 [6-2]
R1-Zero 式"纯 RL 涌现自我验证"的正确解释是？
- A. RL 发明了训练数据里没有的新能力
- B. RL 放大预训练分布里低频存在的有效模式——基座 pass@k 包络内的模式被可验证奖励持续加权，涌现上限由基座覆盖度决定
- C. 是 RM 的功劳
- D. 数据污染
答案：B
解析：策略梯度只加权高奖励轨迹；基座里小概率的"先验算再提交"轨迹统计上答对率更高，被放大成高频。若基座分布里该模式概率≈0，RL 无米下锅——选基座比调 RL 超参更根本。

## Q10 [6-2]
把 RL 训练映射到系统设计：长 CoT RLVR 的三个资源池是？
- A. 只有一个训练集群
- B. 生成集群（rollout 长序列）+ 训练集群 + 沙箱集群（跑单测/验证奖励），配 6-6 的权重同步与速率失配管理
- C. CPU 集群即可
- D. 存储集群为主
答案：B
解析：RLVR 的 rollout 是 8K~32K token 的长生成，生成墙钟远超一步训练（速率失配 U 公式见 6-6）；代码奖励要沙箱执行。RL 系统 = 三类资源的编排，不是"训练框架加个 loss"。

## Q11 [6-3]
奖励模型过优化的最优停止点 d* 由什么决定？
- A. 训练步数
- B. RM 质量：一阶模型 U_gold(d)=g(d)−κd 中 g′(d*)=κ——RM 误差系数 κ 越大，d* 越早；集成 n 个 RM 使 κ→κ/√n，d* 放大 n 倍（α=3、κ=1 时 d*=2.25 nats 量级）
- C. 学习率
- D.  batch size
答案：B
解析：代理奖励单调升（RM 视角永远在涨），真实效用 ∩ 形先升后降。Gao et al. 2023 实测 KL 到 ~10 nats 后 gold 转平/下降。提升 RM 质量（数据/集成/PRM）比调 RL 超参更能推迟崩溃点。

## Q12 [6-3]
BoN（best-of-n）与 RL 的关系，正确的是？
- A. BoN 永远等于 RL
- B. BoN 是推理时选择（成本 ×n），RL 把信号压回权重（泛化更好）；BoN 的选择压力随 n 以 √(2lnn) 增长、过优化更快，是 RL 的"快进版"——快进也包括变坏
- C. BoN 没有过优化风险
- D. RL 推理更贵
答案：B
解析：期望最大值 ≈ μ+σ√(2lnn) 超线性涨，且 BoN 无 KL 约束。"BoN≈RL 的极限"只在同时带 KL 纪律时成立，裸 BoN 是直奔过优化区间的捷径。

## Q13 [6-4]
RFT（拒绝采样微调）的收益上界是？
- A. 无上界
- B. 基座的 pass@k——采 k 个全错的 prompt 产不出正样本，本地产不出能力；突破要靠 RLVR 在线探索或换基座
- C. 与 k 无关
- D. 数据量
答案：B
解析：RFT 数据全部来自当前策略采样，只能在基座能力包络内重新分配概率质量、不能扩大包络。预算紧且 pass@k 已高时 RFT 是正确工具；pass@k 低才上 RLVR。

## Q14 [6-4]
自训练熵坍缩的机制与防控，正确的是？
- A. 熵永远不变
- B. 每轮熵损 ∝ 分布对数概率方差——分布越尖坍缩越快（自加速）；防控：外部数据回放（方差项 ×(1−α)²）、KL 正则拴 ref、组内采样保探索
- C. 只能靠更多算力
- D. 与数据来源无关
答案：B
解析：Shumailov et al. 2024 的递归自训练丢失尾部。均匀分布方差≈0（自训练不改分布），尖分布方差大（削尾部后更尖）。防控要在分布还"胖"时启动，等尖了再管方差项已经很大。

## Q15 [6-5]
"对齐税"的干净度量必须包含？
- A. 只看对齐后的绝对分
- B. 同 harness、同模板、同解码参数、多 seed 报置信区间，且用安全无关子集——否则"少答危险题"会被误记为能力涨
- C. 跑一次即可
- D. 换一个更差的基线
答案：B
解析：harness 差 1 个点是常态；2.5 点可能落在噪声内（7-2 显著性）；中间换 tokenizer/模板就不是"税"是换了模型。缓解靠通用数据混入对齐阶段——税是数据配方问题不是定律。

## Q16 [6-5]
GCG 对抗后缀看起来像乱码的原因是？
- A. 随机初始化没训练
- B. 优化目标只是 −log P(目标输出)，不约束可读性——后缀通过 token 序列的分布效应把模型内部状态推进"顺从模式"，语义从不是约束
- C. 编码错误
- D. 数据噪声
答案：B
解析：梯度搜索找的是高维统计捷径。可迁移（开源搜→闭源中招）因为不同模型的"顺从模式"表征部分共享。防御含义：闭源 API 不能假定梯度不可见就安全，乱码后缀的统计特征本身可检出；防御靠分层而非静态墙。

## Q17 [6-7]
大模型备案材料与工程流水线的对应，错误的是？
- A. 安全评估报告 ← 评测 harness（ASR/过度拒绝/拒答集）
- B. 语料说明 ← 语料入库 CI 的 license/PII 扫描
- C. 备案材料应该上线前两周集中人工补，保证新鲜
- D. 模型卡 ← 训练流水线自动生成 + schema 校验
答案：C

## Q18 [6-7]
内容安全"双轨过滤"的三难与分层解法？
- A. 只要输出过滤
- B. 误伤率/漏过率/延迟不可兼得——分层：快筛（敏感词，μs）→ 分类器（ms，流式）→ 人工抽检（0.1%~1% 流量），每层误判回流成下一层训练数据
- C. 只靠训练层拒答
- D. 过滤越严越好
答案：B
解析：训练层（拒答 RL）与服务侧系统层是双轨；输出侧分类器要独立于被保护模型（别用被保护的模型守自己）。三层是同一数据闭环的三个采样率，不是静态管道。过滤阈值按误伤/漏过的业务代价定。

## Q19 [6-6]
RL 系统工程中 rollout 与训练的速率失配，正确的利用率模型是？
- A. 两边永远 100%
- B. U=(n_t·T_t+n_g·T_g)/((n_t+n_g)·max(T_t,T_g))——生成慢（T_g>T_t）时训练卡干等；缓解靠异步 RL/权重同步分层/生成侧连续批处理
- C. 只与 batch 有关
- D. 加卡就能解决
答案：B
解析：6-6 §2 的模型：同步 RL 下 step 时间 = max(T_g,T_t)，慢的一方拖全程。长 CoT RLVR 里 T_g 常 5~10 倍于 T_t——异步、分桶、部分重叠是标配，代价是 off-policy 校正与staleness 管理。

## Q20 [6-1]
只有"点赞/点踩"单条反馈（无成对数据）时选哪种对齐方法？
- A. DPO
- B. KTO——前景理论效用函数把单条二值反馈变成"比当前平均好/坏"的信号，不需要配对
- C. PPO
- D. 无法对齐
答案：B
解析：DPO 的结构是 chosen−rejected 差分，无 rejected 时无定义。KTO 的代价：单条信号方差大、需要一个参考 batch 估计当前平均水平、得失权重超参敏感。
