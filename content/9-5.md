## why

9-0~9-4 铺完了多模态全部技术组件，本单元是收口：**多模态模型从预训练到对齐的完整课程 + 评测体系**。你会把前五个单元的一切放进"三阶段训练 + DPO 对齐 + 分能力评测"的框架里，重点解决三个多模态特有的难题：幻觉（说图里没有的东西）、评测污染（公开集泄漏严重）、以及对齐数据构造（6-x 的方法在多模态怎么用）。这是把一个 VLM 从"能跑"推到"能用"的最后一段路。

## body

### 1. 完整训练课程（工业配方级）

```
阶段 0  双冻结投影对齐    1M 图文对，冻结编码器+LLM，只训投影器
阶段 1  视觉指令 SFT      665K~1M 指令数据，解冻 LLM（或 LoRA）
阶段 2  多模态 DPO       10K~100K 偏好对，6-1 的 DPO 方法直接复用
阶段 3  （可选）RLHF     MM-Vid 式片段级奖励，GRPO 组内比较（6-2）
```

**各阶段的数据账**（复现级配方，以 7B LLM 为底座）：

| 阶段 | 数据量 | 可训参数 | 算力（8×A800 估算） |
|---|---|---|---|
| 0 | 1.2M 图文对 | 投影器 8M | ~0.5 天 |
| 1 | 665K 指令 | 7B 全参（或 LoRA 40M） | 1~3 天 |
| 2 | 10K~100K 偏好对 | 7B（DPO 训 actor，ref 冻结） | 0.5~2 天 |
| 3 | 5K~50K 视频 | 7B + 冻结奖励模型 | 2~5 天 |

**关键教训**：阶段 2 的偏好数据**质量远重于数量**——RLHF-V 只用 10K 条人工校正样本（比通用 RLHF 的 100K 小一个量级）就把幻觉率从 54% 砍到 12%，因为每条样本都是"指出具体幻觉片段 + 正确描述"的密集监督，而不是模糊的"好/坏"标签。

### 2. 多模态幻觉：三层归因与对策

幻觉（描述图里不存在的物体）的三个来源，对策各不相同：

| 层 | 机制 | 检测 | 对策 |
|---|---|---|---|
| 数据 | caption 噪声（LLM 生成的训练数据本身有幻觉） | 抽样人审 | 数据过滤 + 拒绝采样（用检测器打分） |
| 训练目标 | 语言先验压过视觉证据（LLM 倾向补全"合理"句子） | 图像置换对照（9-0 练习 6） | 视觉证据加权损失（增大视觉 token 的注意力权重） |
| 解码 | 采样多样性 | 多次采样一致性 | 自洽性投票（10-2 同款） |

**系统对策是 RLHF-V 路线**：构造"生成答案 → 检测器定位幻觉片段 → 人工/模型校正 → (原答案, 校正答案) 偏好对"的数据飞轮，然后 DPO。**注意 6-1 的似然位移风险同样存在**：DPO 会整体压低 chosen 的绝对概率，多模态场景表现为"变保守"（更多弃答）——监控弃答率防过度矫正。

### 3. 评测体系：公开集 + 私有集 + judge

**公开基准**（只用做 PR 口径，防污染靠 7-1 纪律）：

- **MME**：感知（存在性/计数/位置/颜色）+ 认知（名人/场景/艺术/地标）14 个子任务，总分 + 分项——**分项报告是防"平均分掩盖偏科"的关键**
- **MMMU**：大学级多学科（30 门课），带私有测试集防泄漏
- **TextVQA / DocVQA / ChartQA**：OCR/文档/图表三个专项
- **POPE / CHAIR**：幻觉专项（POPE 用是/否问题测物体级幻觉；CHAIR 用描述里的虚构物体率）

**私有评测集**（7-4 的四来源法）按能力分桶：通用描述 / OCR 文档 / 图表推理 / 计数 / 空间关系 / 视频时序。**每桶都要配"图像置换对照组"**——把测试图换成噪声/打乱/置换，如果准确率不掉，说明模型在靠文本先验猜（这是 9-0 练习 6 的批量版）。

**LLM judge 的修正**（7-4 三偏差在多模态全部继承，外加一个多模态特有偏差）：judge 偏爱"描述详细"的答案（长度偏好多模态版）⇒ 细则里明确"只评事实正确性，详细但虚构的答案得 0 分"。

### 4. worked example：VLM 上线前的评测报告模板

**模型**：7B VLM v3，底座 Qwen2.5-7B，SigLIP-SO400M，anyres 4×4。

```
【公开集】MME 感知 1724/认知 585（+38 vs v2）；MMMU 41.2%；TextVQA 78.1%
【私有集】六桶 bootstrap CI：通用 81±2 / OCR 69±3 / 图表 58±4 /
         计数 64±5 / 空间 71±3 / 视频时序 52±6（视频桶缺口最大）
【幻觉】POPE 是/否准确 87%；CHAIR_i 虚构率 3.8%（v2 为 7.1%）
【置换对照】六桶在图像打乱后平均掉 26 点（v2 掉 11 点 ⇒ v2 更依赖先验）
【judge】κ=0.71，双序一致率 82%
【结论】感知+去幻觉显著提升；图表推理与视频时序是下一阶段数据重点；
       置换对照证明视觉证据权重真实上升
```

**这份报告每个数字都带 CI、每项都有对照、每个结论都有分层**——7-2 的统计纪律 + 7-4 的架构纪律在多模态的完整落地。

## ex

**练习 1（对应退出标准 1）** 复述四阶段训练课程的数据账，指出哪阶段数据质量权重最高、为什么。

%%%

顺序为投影对齐、视觉监督微调、多模态偏好对齐、可选可验证奖励优化。原表数量只能作预算示例，非通用工业配方；每阶段都需质量控制。偏好阶段尤其依赖正确、可核验且不只偏爱拒答的chosen/rejected。

**练习 2（对应退出标准 2）** 多模态幻觉的三层归因各对应什么对策？RLHF-V 的数据飞轮怎么切断"语言先验压过视觉证据"的循环？

%%%

数据层清洗图文不一致；目标层用对照和偏好数据强化视觉证据；解码层用核验、拒答和受控采样。定位具体幻觉再人工修正可提供更细监督，但仍要独立留出集验证；提高注意力权重或多次投票不自动保证真实性。

**练习 3（对应退出标准 3）** POPE 和 CHAIR 分别怎么测幻觉？为什么幻觉要有专项指标而不是混在通用准确率里？

%%%

POPE以物体存在性问题检查虚构，需同时看准确率、精确率、召回和回答偏置；CHAIR检查生成描述里的虚构物体，可按物体或句子统计。通用准确率会掩盖少量但严重的编造，也可能被一律拒答“改善”。

**练习 4（对应退出标准 4）** 私有集六桶各配图像置换对照组的意义是什么？打乱后掉 26 点与掉 11 点分别说明什么？

%%%

置换是使用视觉信息的敏感性对照。掉26点比11点可能说明更依赖输入图，但还受原始准确率、难度、分布外影响；应分桶、给配对区间，并加入等难度图和人工证据核对，不能单凭下降证明推理更真实。

**练习 5（对应退出标准 5）** 用 worked example 的报告模板，给一个"通用强但 OCR 弱"的 VLM 写评测结论，指出下一步数据动作。

%%%

结论模板：在固定版本留出集上通用任务达标，OCR仍低于预设门槛（填实测值与区间），不可宣称整体满足文档场景。下一步增加小字/中文/复杂版面且答案可核验的数据，对分辨率、视觉token预算、编码器做单变量对照。

**练习 6（对应退出标准 6）** 多模态 DPO 后模型弃答率从 5% 涨到 18%。诊断可能原因（提示 6-1 的似然位移），给出监控与回调方案。

%%%

可能是偏好对更偏爱拒答、数据不可答比例增加、似然位移或解码阈值变化。分别测可答/不可答桶的正确回答率、过拒率、幻觉率和chosen/rejected logprob；回滚异常检查点、调整配方或加监督项，并用独立集选择β和早停点。
