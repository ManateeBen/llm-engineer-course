## why

清洗去重之后，摆在你面前的是几个来源迥异的域：网页、书籍、论文、代码、百科。**每个域都训一点，模型就是"都会一点、都不精通"；配比不是审美问题，是预算问题**——同样的 token 预算，喂给不同域的边际收益完全不同，而错误的配比到训练后期才能发现，返工成本是千万级算力。

这个决策为什么难：**你不可能对每个候选配比都跑一次全规模训练**。于是问题变成两级——第一级，在小模型上高效地**找到好配比**（DoReMi、数据混合定律）；第二级，在训练末期**把高质量数据集中火**（退火）。本单元把这两级的算法与工程实践讲透。

## body

### 域配比为什么重要：一次思想实验

假设语料里网页占 95% token、书籍占 5%。直观上"尊重原始分布"最自然，但这意味着：**书籍这类知识密集、文本质量高的域只被学了 5% 的步数**。Gopher 的报告用消融实验证明：把书籍、维基这类域**上采样**（upsampling，即提高采样比例，哪怕原始占比很小）能显著改善知识型任务，代价是网页域略微变差。

直觉解释：模型的最终能力是各域 loss 的加权平均，而**各域把 loss 压下去的难度天差地别**——网页噪声大、模式杂，loss 降得慢；书籍结构化、知识密，同样的 token 投进去降得快。1-1 学过交叉熵：训练目标就是压下一页文本的困惑度；**困惑度下降本身就是域重要性的量化信号**。

### 域内回报递减：为什么"雨露均沾"不是最优

固定总 token 预算 \(N\)，分给 \(m\) 个域。每个域单独训练时，loss 随 token 数呈幂律下降（2-3 的缩放律，这里套用到域级）：

\[
L_i(N_i)=L_i^\infty+a_i\cdot N_i^{-b_i}
\]

- \(L_i^\infty\)：该域的**不可约 loss**（内容本身的熵，网页高、代码低）
- \(a_i\)：起点高度；\(b_i\)：下降速率

把预算全部压给一个域，它的 loss 很快触底（\(N_i\to\infty\) 时 \(L_i\to L_i^\infty\)），**继续投入的边际收益趋近于零**；而其他域完全没学。总 loss 是各域的加权和，最优解一定在**边际收益相等**的地方——这就是经济学里"等边际原则"的数据版：

\[
\frac{\partial L_{\text{total}}}{\partial N_1}=\frac{\partial L_{\text{total}}}{\partial N_2}=\cdots
\]

比喻：一桌人分馒头，饭量大的人多吃一个才饱，饭量小的人半个就撑——**按边际饱腹感分，不按人头分**。数据配比就是给各个域分馒头：哪一域的 loss 还对 token 敏感，就多喂；哪一域已经躺平，就减量。

### DoReMi：在小模型上试出好配比

问题回到工程：全规模试错太贵。DoReMi（Xie 2023）的三步棋：

1. **代理训练**：先用均匀配比训一个小的**域参考模型**（domain model），得到每个域的 loss 基线；
2. **域权重优化**：在代理模型上用组内 DRO（group distributionally robust optimization）训练——每一批都**优先优化当前最差的域**，迭代几百步就得到一组域权重 \(w\)；
3. **正式训练**：用优化出的 \(w\) 训练主模型。

效果：在 130M 代理上花约 0.1% 的总算力找到的配比，用到 8B 主模型上，**平均 2.6 倍加速**（达到基线同样质量只需约四成步数）。关键在于**配比有迁移性**：小规模上"哪些域值得多学"的结构性结论，在大规模上依然成立。

### 数据混合定律：更直接的预测

数据混合定律（Chen 2024）把配比问题变成纯数学：先用小规模实验测出每个域单独训练的缩放参数 \((L_i^\infty, a_i, b_i)\)，再利用一个经验关系——**混合体的 loss 指数随域权重平滑变化**——直接预测**任意配比、任意规模**下的 loss，不用真跑。在 100M~1.5B 上验证，预测的 loss 与实测误差在 0.1% 量级。

用法：在网格上搜索使"预测的大模型 loss"最小的权重向量，一次小规模扫描拿到全规模最优配比。这是 4-4 代理实验思想在配比问题上的标准应用——**小规模上买信息，大规模上买质量**。

### 数据受限时的账：重复喂也有边界

如果高质量数据总共就那么多（数据受限场景），把仅有的语料**重复喂 2~4 个 epoch** 几乎不损失质量，但超过约 4 个 epoch 后收益锐减（Muennighoff 2023）。配比决策因此多一条硬约束：**去重后的唯一 token 总量是天花板**（4-0 的去重直接决定这个天花板），不够时优先补数据而不是加 epoch。

### 数据退火：最后一口要吃精粮

**退火（annealing）**指训练末期（最后 5%~10% 步数）做两件事：学习率衰减到接近 0（2-4 的 warmup 对面），同时**把数据分布切换到高质量子集**——提高书籍、论文、精选代码的采样比例，降低网页噪声比例。

类比金属热处理：普通钢反复锻打成型（大规模混合数据打基础），最后**蘸火定形**（高质量数据 + 小学习率收尾）——末期模型参数已经就位，正是对细粒度模式最敏感的时候，此时喂精粮，知识型任务的收益最大。MiniCPM 等技术报告显示：退火段换用高质量数据 + 学习率衰减到 0，最终 checkpoint 的质量提升明显，而这一步的算力开销只占总训练的几个百分点。

配套的还有**学习率退火的形状选择**：cosine 平滑降到峰值的一小部分；WSD（warmup-stable-decay）先恒定再快速衰减，方便中途暂停出中间版本。数据退火与学习率退火必须**同步规划**——学习率已经在 0 附近，数据分布却还在大幅切换，等于末期白训。

### 判断框架

设计配比方案时按顺序回答：

1. **域清单与预算**：有哪些域、各多少唯一 token（去重后）？总预算折合多少 epoch？
2. **配比来源**：拍脑袋 / 小规模消融 / DoReMi / 混合定律搜索？后两者要留出代理训练预算（约总量 1% 以内）。
3. **退火规划**：末期多长、高质量子集怎么定义、学习率形状与数据切换是否对齐？
4. **验证闭环**：配比效果只在 loss 上看是不够的，抽 2~3 个下游探针任务确认没有"loss 降但能力不涨"（4-4 的代理实验专门拆这个坑）。

## ex

**练习 1（对应退出标准 1）**
为什么"按语料原始占比配比"通常不是好选择？Gopher 的做法给了什么反例？

%%%

**参考答案：**
原始占比由"数据好不好获取"决定，而非"对模型是否有价值"。网页天然占 95%+，若照此配比，知识密集的书籍/百科只被学几个百分点，下游知识任务吃亏。Gopher 的消融显示：把书籍、维基等高质量/知识密集域上采样（超出其自然占比）能改善知识任务，虽然网页域略降——说明配比应按学习价值而非数据存量分配。

**练习 2（对应退出标准 2）**
写出域级幂律 \(L_i(N_i)=L_i^\infty+a_iN_i^{-b_i}\)，并用它解释为什么最优配比满足"边际 loss 下降相等"。

%%%

**参考答案：**
各域单独训练 loss 随 token 幂律下降，\(L_i^\infty\) 是不可约 loss、\(b_i\) 是下降速率。总 loss \(L=\sum_i w_iL_i(N_i)\)（\(w_i\) 权重、\(\sum N_i=N\)）。若域 A 的边际下降 \(-w_i b_i a_i N_i^{-b_i-1}\) 大于域 B，把 B 的一个 token 移给 A 总 loss 降得更多——最优时各域边际相等，否则转移预算还能改善。这就是等边际原则：按"哪个域还对 token 敏感"分配。

**练习 3（对应退出标准 3）**
DoReMi 的三步是什么？为什么它的小规模配比结论能迁移到大规模？

%%%

**参考答案：**
① 均匀配比训小的域参考模型；② 在其上用 group DRO 训练优化域权重（每批优先优化最差域）；③ 用得到的权重训主模型。迁移性来自结构性结论：哪些域"值得多学"由各域的 loss 曲面形状决定，小规模上即可辨认（下降快的域边际收益高），这个排序对规模稳健——所以约 0.1% 算力的代理训练能换来 2.6 倍加速。

**练习 4（对应退出标准 4）**
数据混合定律预测配比的基本输入是什么？它和 4-4 的代理实验思想是什么关系？

%%%

**参考答案：**
输入：各域单独训练的缩放参数 \((L_i^\infty,a_i,b_i)\)（小规模实测）+ 混合 loss 指数随权重变化的经验关系；输出：任意配比/规模下的预测 loss，网格搜索即得最优配比。这正是代理实验思想的标准案例：用可负担的小规模实验测出结构参数，再外推全规模结论，避免在大模型上直接试错。

**练习 5（对应退出标准 5）**
数据受限时，"重复喂同一份数据"的边界在哪里？4-0 的去重如何进入这个决策？

%%%

**参考答案：**
去重后的唯一 token 决定天花板：重复 2~4 个 epoch 质量几乎无损，超过约 4 个 epoch 收益锐减（Muennighoff 2023）。去重越强，唯一 token 越少、天花板越低——所以去重与配比是联动决策：强去重后若唯一 token 不足，应补数据而非加 epoch，且退火用高质量子集时更要按去重后的真实量规划 epoch 数。

**练习 6（对应退出标准 6）**
数据退火退的是什么？为什么它必须和学习率退火同步规划？

%%%

**参考答案：**
退火 = 训练末期（最后 5%~10% 步数）学习率衰减到接近 0，同时把数据分布切到高质量子集（书籍/论文/精选代码占比提高）。必须同步：末期模型对细粒度模式最敏感、参数已就位，是"定形"窗口；若学习率已衰减到近 0 而数据还在大幅切换，切换带来的梯度被小学习率吃掉，等于白切；反之学习率还在高位就切数据，等于用大数据学习率训小高质量集，浪费了精粮也扰乱收敛。
