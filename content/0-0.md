## why

这门课后面 73 个单元几乎每一页都有公式。不会读公式的人，看论文、看技术博客、看面试官写在白板上的推导，全都像看天书。但"会读公式"不是天赋，是一个可以三分钟学会的机械流程：**任何公式，先看它要什么原料、算什么步骤、出什么结果**。

本单元就是教你这件事，然后给你一张全课地图。花 15 分钟读完，后面 70 多个单元会顺得多。

### 读公式的三招（拿一个真公式练手）

以语言模型最核心的交叉熵损失为例（阶段 6 之前你会反复见到它）：

\[
L = -\frac{1}{N}\sum_{i=1}^{N} \log p(y_i \mid x_i)
\]

**第一招：读名字。** 先问"它叫什么、多半是干嘛的"。\(L\) 是 loss（损失），\(\log\) 是对数，\(p\) 是概率。名字就告诉你：这是一个"用概率算损失"的公式。

**第二招：读形状。** 看有几个分组符号（\(\sum\)、\(\frac{}{}\)、\(\sqrt{}\)），公式的骨架就这几样。这里有两层：外层 \(\frac{1}{N}\) 是"平均"，内层 \(\sum\) 是"把 N 个东西加起来"。所以它先算 N 个样本各自的"某个量"，加起来取平均。

**第三招：代数字。** 这是最容易被跳过、但最有用的一招。假设只有 2 个样本，模型给第一个正确词的概率 \(p(y_1\mid x_1)=0.5\)，第二个是 \(0.25\)。那么：

\[
L = -\frac{1}{2}\left(\log 0.5 + \log 0.25\right)
\]

假设这里的 \(\log\) 以 2 为底，\(\log 0.5=-1\)，\(\log 0.25=-2\)（这个算法在阶段 0 第 5 单元教，这里先用结论），于是：

\[
L = -\frac{1}{2}(-1-2) = \frac{3}{2} = 1.5
\]

**现在这个公式对你不再神秘了**：它把每个样本的"预测概率"翻成一个叫"损失"的数，N 个样本取平均。至于 \(\log\) 为什么在这、为什么有个负号，单元 0-5 会从"惊讶程度"一路推给你。

> 比喻：读公式像读菜谱。先看菜名（名字），再看分几步（分组符号），最后试做一小锅（代数字）。没人天生会读公式，都是这么机械地读上几十遍就会了。

### 本课的符号约定

所有符号**只在第一次用到处就地教**，这是写进规格的铁律。这里先给你一张总表，忘了就回来查：

| 符号 | 读法 | 第一次出现 | 一句话含义 |
|---|---|---|---|
| \(f(x)\) | f of x | 0-1 | 一台机器：吃 x，吐一个数 |
| \(w, b\) | 权重、偏置 | 0-1 | 机器上可调的旋钮 |
| \(x, \mathbf{v}\) | 标量、向量 | 0-2 | 一个数；一列数 |
| \(W\) | 矩阵 | 0-2 | 一张数字表格 |
| \(\sum\) | 求和 | 0-2 | 把一串数挨个加起来 |
| \(\Delta, \partial\) | 差分、偏导 | 0-3 | 走一小步；只对一个方向求坡度 |
| \(\log\) | 对数 | 0-5 | "有几个零"的度量 |
| \(p(y\mid x)\) | 条件概率 | 0-5/0-8 | 已知 x 时 y 的概率 |
| \(\|\mathbf{v}\|\) | 范数 | 1-0 | 向量的"长度" |

### 每个单元的正确打开方式

每个单元固定五段，按顺序读：

1. **为什么学这个**：不学它会卡在哪。先建立动机，再进内容。
2. **正文**：从具体数字例子推到抽象公式，每个抽象概念配一个比喻。
3. **练习**：4~6 题，答案折叠在题后——**先自己做完再展开**。练习直接覆盖退出标准。
4. **退出标准**：可检验的动作清单。全部做到，才点"标记为已学完"。
5. **原始文献**：3~6 条真实出处，想深挖按图索骥。

每阶段末尾有 **gate 大测**（10~15 题综合测），做对 ≥80% 才解锁下一阶段。做错的题自动进首页错题本。

> 比喻：退出标准就是驾校的"科目二过关标准"。不是"我看过了"，而是"我能做出来"。

## ex

**练习 1（对应退出标准 1）**
用"三招"读下面这个公式，说出它的名字、骨架、以及当 \(a=2, b=3\) 时它的值：

\[
E = \frac{1}{2}(a - b)^2
\]

%%%

**参考答案：**
- 名字：平方误差的一半（机器学习里最常见的损失原型）。
- 骨架：外层 \(\frac{1}{2}\) 是常数，核心是 \((a-b)^2\)——先算差，再平方。
- 代数字：\((2-3)^2 = 1\)，所以 \(E = 0.5\)。

**练习 2（对应退出标准 2）**
不查资料，用自己的话说出 \(\sum_{i=1}^{3} x_i\) 是什么意思，并算出 \(x_1=2, x_2=5, x_3=-1\) 时的值。

%%%

**参考答案：**
把 \(i=1,2,3\) 逐个代入 \(x_i\) 再相加，即 \(x_1+x_2+x_3 = 2+5+(-1) = 6\)。\(i\) 叫"索引变量"，\(\sum\) 下面写起点、上面写终点，表示"从这个范围挨个取来加"。

**练习 3（对应退出标准 3）**
打开课程首页的"环境准备"，在你自己机器（或云端）上跑 `python -c "import torch; print(torch.cuda.is_available())"`。输出是什么？如果没有 GPU，输出 `False` 是正常的，记下你的实际输出。

%%%

**参考答案：**
有 NVIDIA GPU 且驱动/ CUDA 正常时输出 `True`；否则输出 `False`。两条路都能继续本课：CPU 可跑单元 0-6 与 micrograd 级别代码；GPU 级训练留到 P2 各项目的 README 要求处。**关键是现在就知道自己的起点**，不要等到阶段 4 才发现环境没准备好。

**练习 4（对应退出标准 4）**
说出从 0-0 到 0-8 的正确学习顺序，并说明：如果直接跳去读 3-0（Transformer），按本课设计会先撞上哪三个前置缺口？

%%%

**参考答案：**
顺序即编号 0-0 → 0-8。直接读 3-0 的三个缺口：① 读不懂矩阵记号与"加权求和"（0-2）；② 读不懂导数/梯度/链式法则，而 Transformer 全文是矩阵求导（0-3、0-4）；③ 读不懂概率与对数，而注意力的 softmax 与训练的交叉熵都是概率语言（0-5）。这就是 `pre` 字段存在的意义。
