## why

阶段 4 讲过数据配比，阶段 7-0 讲过 benchmark 设计——但如果测试题的答案出现在了训练数据里，前面所有严谨都是幻觉。污染是 LLM 评测的癌症：GPT-4 级别的模型在 GSM8K 上 92%，其中有多少是"见过原题"贡献的？本单元给你三种检测武器（成员推断、时间旅行、黑盒检验）和一条工程上可落地的反污染流水线。学完后你能给任何内部评测集出一份污染审计报告。

## body

### 1. 污染的形式化定义与代价模型

**定义**：测试样本 \(x=(q,a)\) 被污染，当且仅当 \(q\)（或其近邻）出现在预训练语料 \(\mathcal{C}_{\text{pre}}\) 中。设真实能力分数为 \(s_{\text{true}}\)，观测分数 \(s_{\text{obs}}\)，污染题占比 \(p\)，污染题上的虚高分为 \(\Delta\)：

\[
s_{\text{obs}} = (1-p)\,s_{\text{true}} + p\,(s_{\text{true}}+\Delta) = s_{\text{true}} + p\Delta
\]

**关键洞察**：污染不是 0/1 问题而是连续剂量问题。\(p=1\%,\Delta=50\) 点 ⇒ 虚高 0.5 点（可忽略）；\(p=5\%,\Delta=50\) 点 ⇒ 虚高 2.5 点（足以颠倒模型排名——7-2 会看到典型 CI 宽度正是 2~3 点）。**所以审计报告要给 \(p\Delta\) 的联合估计，不是"是否污染"的布尔值。**

### 2. 检测武器一：成员推断（Min-K% Prob）

白盒路径：用模型自身给测试题打逐 token 对数概率。核心观察——**见过的话，逐 token 概率分布整体偏高且更不平坦**。

**Min-K% Prob 步骤**：

1. 对测试样本 \(x\) 的每个 token 位置 \(i\)，取模型给的真实 token 的对数概率 \(\ell_i=\log p_\theta(x_i\mid x_{<i})\)
2. 取 \(\ell_i\) 最小的 \(K\%\) 位置，求均值 \(\mu_K=\operatorname{mean}(\text{bottom-}K\%\,\ell)\)
3. 与"未见语料"参考分布比较：\(\mu_K\) 显著高于参考 ⇒ 疑似成员

直觉：生成见过的句子时模型几乎不"犹豫"，连低概率位置都偏高；生成新句子时低概率位置暴露真实的不确定性。WikiMIA 上此方法 AUC 可达 0.7+，配合参考分布校准后更高。**局限**：只适用于能拿到 logits 的白盒；对 paraphrase 污染（题目改写）无效。

### 3. 检测武器二：时间旅行（构造免疫区）

**原理**：预训练语料有截止时间 \(t_{\text{cut}}\)。把测试题全部换成 \(t_{\text{cut}}\) 之后产生的内容——模型物理上不可能见过。Golchin & Surdeanu 的做法：用"明年世界杯赛程""上月发布的新 API 文档"构造测试集。

\[
P(\text{污染}) = 0 \quad \text{当} \quad t(\text{题目}) > t_{\text{cut}}
\]

**这是唯一给出零污染保证的方法**，代价是题目分布受限（只能测"截止后知识"，不能测推理能力）。工程上的标准用法：**双集制**——主集测能力（接受小污染），免疫集测知识真实性；两者结合才能分离"能力涨"与"背得多"。

### 4. 检测武器三：黑盒可交换性检验

拿不到 logits 时的路径。Oren et al. 的可交换性检验：若题目未被污染，则"模型在测试集上的表现"与"模型在留出集上的表现"来自同一分布。用置换检验（permutation test）算 p 值——把两集合混洗重复分组 \(B\) 次，观测差值在置换分布中的尾部概率就是 p。

**局限**：需要模型确实没在别处背过答案；且对"题目改写后入训练料"（近邻污染）不敏感。与 n-gram 重叠扫描（直接检索训练语料中的 13-gram 重合）互补使用。

### 5. 反污染流水线（工程落地）

```
┌─────────┐   ┌──────────┐   ┌─────────┐   ┌──────────┐
│ 建题    │ → │ 入库扫描 │ → │ 训练中  │ → │ 出榜审计 │
│ 元数据  │   │ 13-gram  │   │ 名单制  │   │ 全流程   │
│ 记录    │   │ 去重     │   │         │   │          │
└─────────┘   └──────────┘   └─────────┘   └──────────┘
```

1. **建题阶段**：每题记录来源 URL、抓取时间、改写历史。时间晚于 \(t_{\text{cut}}\) 的进免疫集
2. **入库扫描**：对训练语料跑 MinHash 去重（4-0 的同款工具），与测试题做 13-gram 重合检索；重合率 > 0 的题进隔离区
3. **训练中名单制**：数据 pipeline 维护 blocklist（测试题哈希集合），新数据入库先查 blocklist——这是大厂的标配
4. **出榜审计**：对每个候选模型跑 Min-K% + 免疫集双轨，输出污染剂量报告 \(p\Delta\)

### 6. worked example：审计一个 200 题数学集

**背景**：内部数学评测集 200 题，模型 A 报 84%，模型 B 报 79%。决策前先审计。

**步骤 1**：13-gram 扫描训练语料 ⇒ 发现 7 题原文重合（\(p_{\text{exact}}=3.5\%\)）
**步骤 2**：对这 7 题单独统计：模型平均 100%（全对），非重合题平均 82.6%
**步骤 3**：免疫集（用上月新题替换同难度 50 题）重测：A 得 76%，B 得 78%——**排名反转！**
**步骤 4**：剂量报告：A 的 \(p\Delta = 0.035\times(100-82.6)\approx 0.6\) 点虚高，免疫集显示 A 的真实能力反低于 B。

**结论**：不审计就会发布"A 优于 B"的错误结论。**审计成本半天，决策风险是整整一代模型的技术选型。**

## ex

**练习 1（对应退出标准 1）** 用代价模型计算：污染题占比 8%、虚高 40 点时虚高总分多少？这相对 7-0 说的典型 CI 宽度（±2.5 点）意味着什么？

%%%

虚高为 \(0.08\times40=3.2\) 个百分点，大于示例区间的半宽 2.5 点。污染是系统偏差，扩大题量只能缩小抽样误差，不能消除它；需清理污染并重测。

**练习 2（对应退出标准 2）** Min-K% Prob 为什么取"最小的 K%"而不是全部 token 的均值？从分布平坦度的角度解释。

%%%

取低概率尾部 token，是为了观察模型对难预测细节是否仍异常熟悉；全文均值容易被常见词稀释。低尾部损失是成员推断信号而非见过训练数据的证明，也会受文本难度、领域与模型能力影响。

**练习 3（对应退出标准 3）** 时间旅行法的"零污染保证"依赖什么前提？列出两个前提失效的场景。

%%%

需要可核验的模型冻结时间，题目内容在其后首次产生，且推理期间没有检索、持续训练等额外访问。事后题目只是旧题改写，或 API 背后模型已经更新，都破坏前提；时间晚只降低某种暴露风险。

**练习 4（对应退出标准 4）** 你的训练语料里有测试题的 paraphrase（同题不同表述），13-gram 扫描漏检。设计一个两级检测：先用 embed 近邻召回候选，再用什么方法确认？

%%%

先对题干与解答分别做向量近邻召回，再用语义等价判断、结构化答案/推导对照与人工复核确认；阈值在人工标注样本上校准。向量相似可能只是同主题，不能直接认定污染。

**练习 5（对应退出标准 5）** 画出反污染流水线的四个阶段，并说明每阶段能拦哪种污染（原文/近邻/黑盒未知）拦不住哪种。

%%%

流程：基准登记与隔离 → 规范化精确/n-gram 排除 → 语义近邻候选复核 → 冻结后的行为审计与新题评测。前两级处理可见语料的原文重叠，语义级捕捉部分改写，黑盒审计提供异常证据但不能恢复全部训练成员。

**练习 6（对应退出标准 6）** 开源模型报告"在 MMLU 上超过 GPT-4"，但你怀疑训练语料含 MMLU。设计一个最小成本的审计方案（只给你 API 访问权限），并说明每个证据能支持什么强度的结论。

%%%

固定 API 版本和采样参数，抽原题、保留答案的改写题和新编同难度题做配对对照；比较性能差距，并测试能否复现题目独特措辞。API 若不提供 token logprob，就不能直接运行 Min-K% Prob。异常只支持进一步调查，不能据此证明污染或比较所有型号。
