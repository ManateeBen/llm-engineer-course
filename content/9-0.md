## why

你已掌握的 Transformer 只吃离散 token 序列；图像是连续的像素张量 \(H\times W\times 3\)。多模态的第一性问题不是"设计新架构"，而是**翻译**：怎么把图像变成 LLM 能消化的 token 序列，且这个翻译过程不丢任务所需信息。本单元讲 token 化的三种路线（patch、码本、连续投影）、视觉 token 的数量经济学（576 vs 12288 的算力差 20 倍），以及 LLM 侧必须做的适配。这是整个多模态阶段的地基。

## body

### 1. 连续域的 token 化：三条路线

**路线 A：Patch 化（ViT 传统）。** 图像切成 \(P\times P\) 的 patch（典型 14×14 或 16×16 像素），每 patch 展平后线性投影成一个 \(d\) 维向量：

\[
x_p = \mathrm{Flatten}(I[i:i+P,\, j:j+P])\,W_e \in \mathbb{R}^{d},\quad I\in\mathbb{R}^{H\times W\times 3}
\]

\(336\times336\) 图像、\(P=14\) ⇒ 每边 24 个 patch ⇒ **576 个视觉 token**。加上位置编码（可学习或 2D 插值 RoPE）后直接喂 Transformer——**这正是"图像变成 token"的字面含义**。

**路线 B：码本量化（VQ 传统）。** 用 VQ-VAE/VQGAN 学一个含 \(K\) 个码字的码本 \(\mathcal{C}=\{c_k\}_{k=1}^K\)，编码器把 patch 映射到最近码字索引——**图像变成离散整数序列**，与文本 token 同构，可以直接拼接进词表统一建模（如 Chameleon 的统一路线）。

**路线 C：连续特征投影（VLM 主流）。** 预训练视觉编码器（CLIP ViT、SigLIP）输出连续特征图，用一个小投影器（MLP 或 Q-Former）映射到 LLM 的嵌入空间——视觉 token 仍是连续向量，不进词表。LLaVA 配方：CLIP ViT-L/14 + 2 层 MLP + Vicuna。

**三条路线的选择逻辑**：B 路线便于用单一离散词表做自回归生成；连续视觉输入也可配合扩散或其他连续生成头，不能把离散化当作一切图文生成的必要条件。Patch 切分与连续投影可以出现在同一管线中。**理解与生成统一是当前多模态的前沿分歧点**，本阶段主线走 A/C（VLM 理解），生成留给 9-4。

### 2. 视觉 token 的数量经济学

LLM 的上下文窗口是稀缺资源，视觉 token 与文本 token 争抢同一份注意力预算：

\[
N_{\text{vis}} = \left\lceil\frac{H}{P}\right\rceil\cdot\left\lceil\frac{W}{P}\right\rceil
\quad\Rightarrow\quad
\text{序列长} = N_{\text{text}} + N_{\text{vis}}
\]

**注意力成本按序列长平方增长**（1-0 的结论）：1024 文本 + 576 视觉 token 的序列，注意力 FLOPs 比纯 1024 文本高 \((1600/1024)^2\approx 2.4\) 倍。所以"每张图 576 token"不是免费午餐——**分辨率每翻倍，视觉 token 数变 4 倍，注意力成本变 16 倍**。

工程上的三个减压阀：

- **动态分辨率**：按图像长宽比分桶（如 LLaVA-NeXT 的 anyres），避免统一 padding 浪费
- **token 压缩**：相邻 patch 在编码器内部合并（Q-Former 的 query 数 = 32~256；Perceiver/Pooling 直接把 576 压到 64~144）
- **文本-视觉 token 混合配比**：训练时按任务类型动态调整视觉 token 占比，防止视觉 token 淹没语言能力

### 3. 投影层：两个模态的"翻译官"

投影器 \(\phi: \mathbb{R}^{d_v}\to\mathbb{R}^{d_l}\) 是唯一需要训练的新参数（视觉编码器与 LLM 都冻结）。三种设计：

| 设计 | 参数量 | 效果 | 代表 |
|---|---|---|---|
| 线性层 | \(d_v\times d_l\)（依维度计算） | 基线 | LLaVA 原版 |
| 2 层 MLP + GELU | 依两层维度计算 | 更好 | LLaVA-1.5 |
| Q-Former（交叉注意力） | ~100M+ | 压缩 + 强表达 | BLIP-2 |

**训练课程是两阶段**：阶段一冻结两端、只训投影层（图文对，便宜）；阶段二解冻 LLM、混合指令数据（贵）。LLaVA-1.5 的关键消融发现：**阶段二的数据质量（回复的多样性/正确性）比数量更重要**——这是 4-x 数据质量结论在多模态的重演。

### 4. LLM 侧的适配：三个必须处理的点

1. **位置编码扩展**：视觉 token 插入后位置索引如何处理——文本段内 RoPE 插值（对长序列）、2D-RoPE 给视觉 token 单独的位置维度（Qwen-VL 的做法）、或 M-RoPE 把位置 id 按 (t,x,y) 分解
2. **图像占位符**：文本里用 `<image>` 特殊 token 标记插入位置，embedding 查找时替换为视觉特征——类似 10-1 工具调用的占位符机制
3. **注意力掩码**：多图需要明确图像边界、位置与因果约定；比较两图可能需要跨图交互，不应一律禁止。结构化 mask 要与具体训练协议一致

### 5. worked example：给 7B LLM 加视觉能力的最小账本

**教学配置**：7B 语言底座，视觉维度1152，语言维度3584，投影为1152→3584→3584的两层MLP。以下是量级估算，不是某型号的实测复现记录。

忽略偏置，投影参数为 \(1152\times3584+3584^2=16973824\)，约17M，而不是简单把第一层乘二。

阶段一若有1.2M对图文、每图576个视觉token、3轮，总视觉token为 \(D=2.0736\times10^9\)。仅7B底座线性层前向粗估 \(2ND\approx2.90\times10^{19}\) FLOPs，即29.0 EFLOPs。还没计文本token、视觉编码器、注意力和反传输入梯度；冻结LLM权重不代表无需经LLM反向传播到投影层。

阶段二若665K条指令、平均总长2000 token、1轮，全参训练线性层近似 \(6ND=5.586\times10^{19}\) FLOPs。该近似也不包含全部视觉成本。

训练静态显存：7B采用BF16权重/梯度、FP32主权重和Adam两组状态时约112GB；不留主权重的实现约84GB，另加激活与临时缓冲。应先声明实现再计账。

时间需要 \(t=C/(n_{\text{device}}F_{\text{effective}})\)，有效吞吐应实测。8卡跑1.5天是12卡天，不是1.5卡天；没有同硬件、同数据、同目标的基准，不能声称固定200倍杠杆。

## ex

**练习 1（对应退出标准 1）** 比较三条 token 化路线（patch/码本/连续投影）在"理解"与"统一生成"两个目标上的适配性，说明离散路线适用于什么生成假设，是否所有多模态生成都必须离散化。

%%%

Patch 是切分方式，连续投影是把视觉特征映射到语言空间，两者可同时使用；码本产生离散索引。若采用单一离散词表的下一 token 生成，视觉离散化便于复用分类目标；混合连续生成头也能输出图像，因此离散化不是一切多模态生成的必要条件。

**练习 2（对应退出标准 2）** \(1024\times1024\) 图像用 \(P=16\) patch 化得多少视觉 token？若改用 \(P=8\)，token 数与注意力 FLOPs 各变几倍？对 32K 上下文窗口意味着什么？

%%%

P=16 得 \(64^2=4096\) 个；P=8 得 \(128^2=16384\)，视觉 token 变 4 倍。仅视觉自注意力的二次项变 16 倍；含文本的总序列需按实际长度重新算。32K 窗口需另外预留文本、特殊 token 和输出。

**练习 3（对应退出标准 3）** 三种投影器（线性/MLP/Q-Former）的参数量差 100 倍，效果差异的来源是什么？LLaVA-1.5 的消融结论是什么？

%%%

参数取决于具体维度。线性投影约 \(d_vd_l\)，两层 MLP 约 \(d_vd_l+d_l^2\)，Q-Former 还取决于层数和隐藏维。MLP 增加非线性，查询式可压缩 token；LLaVA-1.5 报告其特定设置下 MLP 等改动有效，不证明所有场景存在固定百倍差或能力排序。

**练习 4（对应退出标准 4）** 解释 M-RoPE 为什么把位置 id 分解成 (t,x,y) 三维。多图场景下结构化注意力掩码不加会发生什么？给出构造方式。

%%%

时间、水平、垂直位置编码保留不同维度的关系。多图输入要有图像边界和位置约定，但跨图注意力并非必须禁止，比较两张图恰需交互。只在任务与训练协议要求时定义结构化 mask，并验证因果区域和 padding。

**练习 5（对应退出标准 5）** 复算 worked example 的阶段一算力（逐步列出每项的数值），说明还需哪些信息才能估计卡天和相对收益。

%%%

按修正账本，视觉 token 总数 \(1.2\times10^6\times576\times3=2.0736\times10^9\)。仅 7B LLM 的线性层前向近似 \(2ND=2.90304\times10^{19}\) FLOPs，约 29.0 EFLOPs，还不含文本、编码器、注意力及反传输入梯度。不能据此推导半天或 200 倍；需给硬件实测吞吐与完整图。

**练习 6（对应退出标准 6）** 设计一个实验：判断你的 VLM 是"真的理解图像"还是"靠文本先验猜"。给出对照组设计（图像置换/打乱/空白）。

%%%

固定问题，将原图、其他图、空白图作为配对输入；加入只有看图才能回答的问题和纯文本可答问题作控制。测准确率、拒答率、输出对图像变化的敏感度并给区间。大幅下降支持模型使用视觉，但不能单独证明理解、定位或推理机制。
