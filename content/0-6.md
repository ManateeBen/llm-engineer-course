### NumPy 最小必要集：七招

不用学全 NumPy，本课会反复用到的只有这七招。每招都配一个"验证 0-x 单元结论"的用法：

```python
import numpy as np

# ① 创建数组：向量与矩阵
x = np.array([2.0, -1.0, 3.0])          # 向量 (3,)
W = np.array([[1.0, 0.0, 2.0],
              [-1.0, 3.0, 1.0]])        # 矩阵 (2, 3)

# ② 矩阵乘法（0-2 的 y = Wx）
y = W @ x                               # (2, 3) @ (3,) -> (2,)
print(y)                                # [ 8. -2.]

# ③ 形状（0-2 的内标相等外标定形）
print(y.shape)                          # (2,)

# ④ 求和与均值（0-2 的 Σ）
print(x.sum(), x.mean())                # 4.0 1.333...

# ⑤ 逐元素函数（0-1 的激活函数）
relu = np.maximum(0, x)                 # [2. 0. 3.]

# ⑥ 广播（batch 化：一次算多样本）
X = np.array([[2.0, -1.0, 3.0],
              [0.5, 0.5, 0.5]])         # 2 个样本 (2, 3)
Y = X @ W.T                             # (2, 3) @ (3, 2) -> (2, 2)

# ⑦ 差商验证导数（0-3 的数值方法）
def num_grad(f, x, h=1e-4):
    return (f(x + h) - f(x)) / h
print(num_grad(lambda t: t ** 2, 3.0))  # ≈ 6.0
```

三处值得停下来看的地方：

1. **`@` 就是矩阵乘法**，`*` 是逐元素乘——初学者最常踩的坑。
2. **广播**：`(2,3) @ (3,2)` 一次处理 2 个样本。真实的网络永远在 batch 上跑，不是单个样本。
3. **`h=1e-4` 不是越小越好**——看下面的图：步长减到某个程度后，浮点误差反而让差商开始抖动：

[[VIZ:viz-diff]]

曲线先下降（截断误差减小）后上升（舍入误差增大），中间有个最优点。这是"有限差分"方法的固有误差结构，单元 7-3 讲消融外推、8-1 讲算子精度时都会再遇到它。

**练习 2（对应退出标准 2）**
用 NumPy 重算 0-2 的例子：\(x=(2,-1,3)\)，\(W=\begin{pmatrix}1&0&2\\-1&3&1\end{pmatrix}\)，验证 \(Wx=(8,-2)\)。

%%%

**参考答案：**
```python
import numpy as np
x = np.array([2.0, -1.0, 3.0])
W = np.array([[1.0, 0.0, 2.0], [-1.0, 3.0, 1.0]])
print(W @ x)   # [ 8. -2.]
```

**练习 3（对应退出标准 3）**
用差商函数估算 \(f(x)=x^2\) 在 \(x=3\) 的导数，\(h\) 分别取 1e-1、1e-3、1e-5、1e-7、1e-9。观察输出并解释非单调现象。

%%%

**参考答案：**
本节代码是中心差分。对平方函数，实数精确计算时任意非零 h 都得到 6，因为两个二次项抵消；实际浮点输出约 6.0000000000、6.0000000000、6.00000000004、5.9999999902、6.0000004964。不能用前向差分的 6+h 作为本题答案。要观察截断误差和舍入误差共同形成的 U 形曲线，可改用 exp(x)，并用 exp(3) 作为真值。
\(h\) 大时"截断误差"主导（差商离真值远）；\(h\) 太小时 \(f(x+h)\) 与 \(f(x)\) 极其接近，相减丢掉有效数字，"舍入误差"主导。两条误差曲线叠加成 V/U 形，即本单元配图所示。

**练习 4（对应退出标准 4）**
写出"一次处理 4 个样本"的 NumPy 代码：样本矩阵 \(X\) 为 \(4\times3\)，权重 \(W\) 为 \(3\times2\)，偏置 \(b\) 为长度 2 的向量。要求用到广播。

%%%

**参考答案：**
```python
Y = X @ W + b   # (4,3)@(3,2)=(4,2)，+b 广播到每一行
```
`b` 形状 (2,) 自动沿行方向复制 4 份——这就是广播。
