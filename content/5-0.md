## why

训练超参里，**学习率调度**是唯一一个"全程塑造"损失的旋钮：batch size 决定每步走多远，学习率初值决定从哪儿起步，而调度曲线决定整段旅程的形状。2-4 讲过 warmup 与临界 batch size，本单元回答剩下的问题：**为什么要衰减、衰减到多少、以及为什么前沿模型纷纷从 cosine 换成 WSD**。

这不是审美问题。缩放律研究（Kaplan 2020、Chinchilla）发现：训练末段的 loss 下降几乎完全由学习率曲线决定——同样的算力，调度选错，最终 loss 能差出几个百分点，相当于白烧了三分之一的预算。而 WSD（Warmup-Stable-Decay）还附带一个工程红利：**稳定期可以随时叫停**，随时退出都接近最优，这让"训练到一半发现数据有问题"从灾难变成日常。

## body

### 从 SGD 理论看为什么必须衰减

回顾 1-2：SGD 在损失面上走的是"梯度期望 + 噪声"的叠加。学习率大的时候，参数在最优解附近以半径正比于 \(\eta\) 的球里随机游走——离最优越近，梯度越小，**游走半径却不缩小**，loss 停在一个由 \(\eta\) 决定的平台上，降不下去。

衰减学习率 = 逐步收缩这个游走球。当 \(\eta_t \to 0\)，随机游走的半径 \(\to 0\)，参数才有机会沉到真正的谷底。数学上，对强凸问题 SGD 的最优调度是 \(\eta_t \propto 1/t\)（理论最优）；对非凸的深度学习，实践最优是**前期高位探索、末段快速收缩**的形状——cosine 与 WSD 都是这个思想的具体化。

#### 把"平台"算出来：带噪声的下降引理

上面那句"loss 停在由 \(\eta\) 决定的平台上"是可以精确算出来的。设每步拿到的是**无偏但有噪声**的随机梯度：

\[
g_t=\nabla f(x_t)+\xi_t,\qquad \mathbb E[\xi_t]=0,\quad \mathbb E\bigl[\lVert\xi_t\rVert^2\bigr]=\sigma^2
\]

于是（利用噪声与当前点独立）

\[
\mathbb E\bigl[\langle\nabla f(x_t),\,g_t\rangle\bigr]=\lVert\nabla f(x_t)\rVert^2,\qquad
\mathbb E\bigl[\lVert g_t\rVert^2\bigr]=\lVert\nabla f(x_t)\rVert^2+\sigma^2
\]

把它代进 1-2 已经推过的**带余项二阶泰勒展开（下降引理）**——\(f(x+\Delta)\le f(x)+\langle\nabla f,\Delta\rangle+\frac L2\lVert\Delta\rVert^2\)，取 \(\Delta=-\eta g_t\) 并两边取期望：

\[
\mathbb E\bigl[f(x_{t+1})\bigr]\;\le\; f(x_t)-\eta\Bigl(1-\frac{L\eta}{2}\Bigr)\bigl\lVert\nabla f(x_t)\bigr\rVert^{2}\;+\;\underbrace{\frac{L\eta^{2}}{2}\,\sigma^{2}}_{\text{噪声注入项}}
\]

这个不等式是本单元的理论核心，两项分工明确：

- 第一项是**真下降**：要求 \(\eta<2/L\) 才为正（与 1-2 一致）；
- 第二项是**每步固定被噪声抬升**的量，注意它 \(\propto \eta^2\) 且**永远为正**——就算已经到达 \(\nabla f=0\) 的最优点，它也在不断把 loss 往上推。

两项相抵就是"平台"。令总变化为零求平衡点：

\[
\bigl\lVert\nabla f\bigr\rVert^{2}_{\text{floor}}
=\frac{\;L\eta\sigma^{2}/2\;}{1-L\eta/2}\;\approx\;\frac{L\eta\sigma^{2}}{2}\quad(\eta\ll 1/L)
\]

再把"梯度没降到零"翻译成"loss 没降到最优"。对 \(\mu\)-强凸目标有 \(f-f^{\ast}\le\frac{1}{2\mu}\lVert\nabla f\rVert^2\)，代入即得**平台高度**：

\[
\boxed{\;f-f^{\ast}\;\approx\;\frac{L\sigma^{2}}{4\mu}\,\eta\;=\;\frac{\kappa\,\sigma^{2}}{4}\,\eta\quad(\kappa=L/\mu)\;}
\]

三句结论，每一句都直接来自这个式子的右边：

1. **平台高度正比于 \(\eta\)**——恒定学习率下，loss 永远在最优值上方一个 \(\propto\eta\) 的条带里游走。这不正是正文那句话吗？现在它有系数了：\(\kappa\sigma^2\eta/4\)。**想让 loss 再降一个量级，就得让 \(\eta\) 降一个量级。**
2. **衰减到零才能真正到底**：\(\eta\to0\) ⇒ 平台高度 \(\to0\)，参数才可能真的沉进谷底。也解释了为什么 WSD 的 decay 末端要走得更低——停在 10% 峰值意味着还留着 10% 的平台高度。
3. **它同时解释了"换随机选址"的作用**：把 batch 加大 \(B\) 倍、对 \(B\) 个独立同分布样本求平均，方差缩小 \(B\) 倍（\(\operatorname{Var}= \sigma^2/B\)），于是平台高度也随之除以 \(B\)。**换句话说，"降 \(\eta\)" 与 "加 batch" 是同一个式子里的两个等价旋钮**——这正解释了为什么训练后期常常"同时拉大 batch 并衰减学习率"（5-1 会给出这个耦合的完整算术）。之前把它们当成两条经验，现在它们是一件事。

> 一句话收束本小节：\(\eta\) 不只是一个"步子大小"，它是**随机梯度带来的波动带宽度**。调度曲线的形状，就是这条带子随时间收窄的形状。

### 三条主流曲线：linear、cosine、WSD

把训练全程 \(T\) 归一化到 \(t \in [0,1]\)，初值 \(\eta_{\max}\)，末值 \(\eta_{\min}\)：

**Linear decay**（早期 GPT-3 用）：

\[\eta_t = \eta_{\max}(1-t) + \eta_{\min} t\]

前 60% 几乎不降，末段线性下沉。简单，但末段下降太慢，等于把高学习率拖到了最后一刻。

**Cosine decay**（GPT-3 后期 ~ LLaMA 时代的主流）：

\[\eta_t = \eta_{\min} + \tfrac{1}{2}\eta_{\max}\left(1 + \cos\frac{\pi t}{T}\right)\]

两头变化慢、中段下降快——**中段正是 loss 下降最快的区间**，把"下降能力"集中用在刀刃上。Chinchilla 训练 1.4T token 用的就是 warmup 300 步 + cosine 衰减到 10% 峰值收尾。

**WSD**（Warmup–Stable–Decay，2024 年后成为前沿标配）：

\[\eta_t = \begin{cases} \text{warmup 线性爬升} & t < t_w \\ \eta_{\max} & t_w \le t < t_d \\ \text{decay 段快速下降} & t_d \le t \le 1 \end{cases}\]

全程 \(90\%\)+ 时间保持峰值学习率稳定训练，最后 \(5\% \sim 10\%\) 快速衰减到零。MiniCPM 首次系统使用并公开了它的好处，随后 Llama-3、Qwen 等公开技术报告都采用了 WSD 类调度。

三条曲线的对比是 5-0 可视化的主题——**同样训练预算下，cosine 的最终 loss 通常略低于 linear；WSD 与 cosine 在末段损失上接近，但换来"中途可退出"的自由**。

### 为什么 WSD 能赢：退火即压缩

WSD 的数学直觉来自一个反直觉的观察：**"训练了很久"不等于"学到了很多"**。稳定期里参数在高学习率噪声中持续探索，但真正把探索成果"固化"进参数的，是最后的 decay 段——这一段做的事情叫**退火**（annealing），像金属淬火：高温时原子自由运动（稳定期探索），缓慢降温时它们才锁定到低能晶格（decay 段固化）。

Hägele 2024 从理论上证明：WSD 的 decay 段可以看作对稳定期所有 checkpoints 的"隐式平均"——稳定期采到的一系列解，decay 用一个低学习率的过程把它们压向一个更平滑的区域。这解释了 WSD 的三个工程红利：

1. **随时可停**：稳定期任何一个 checkpoint，接一段 decay，最终 loss 都接近全程衰减的水平。数据泄露了、硬件到期了，损失只是"没跑完退火"，而不是"白跑"；
2. **decay 可以复用**：Wiles 2025 的"hitchhiker"方法——从一个大模型的稳定期 checkpoint 出发，用小算力续一段 decay 继续训练，能免费搭车获得接近全衰减的 loss。这让"用别人的训练成果"第一次变得可行；
3. **中期汇报体面**：稳定期 loss 看起来"平台期不动"，团队知道那是探索期，不会被"loss 不降了"的恐慌逼着改配方。

### 退火段多长？衰减到多低？

两个实操问题的答案都有实证支撑：

**decay 长度**：MiniCPM 与后续工作报告显示，decay 占全程 5%~10% 即可拿到大部分收益；低于 2% 则固化不充分。一个常用配方：warmup 2000 步（或 0.5% 步数）、decay 10% 步数。

**末值 \(\eta_{\min}\)**：Chinchilla 用峰值的 10%；更激进的实践衰减到 0（峰值 1%~3%）。WSD 场景下 decay 末端 \(\eta \to 0\) 效果最好，因为"固化"需要参数真正静止下来。一个实用起点：**cosine 到 10%，WSD decay 到 1% 以下**。

### 与 5-1 的联动：batch size 换来的衰减

2-4 讲过临界 batch size：超过它之后，加大 batch 的收益锐减。缩放律的另一个实用结论是：**训练后期把 batch 拉大、学习率同步衰减**，比恒定 batch 更省算力（Muennighoff 2023 的数据受限缩放律有系统讨论）。所以真实的大训练配方常是"三段式"：warmup → 稳定期（可含 batch 增长）→ decay（batch 达峰、学习率归零）。这也是 5-1 讨论三个量耦合时的调度背景。

### 常见误区

- **误区一**："cosine 一定优于 constant"——在短训练（几十步的实验）或超小步数下差别不大，为调试方便 constant 也够用；结论在千步以上的真实训练才成立。
- **误区二**："warmup 越长越稳"——warmup 超过 2%~5% 步数纯属浪费预算，几百到几千步即可（3-0/2-4 的初始化分析解释了为什么早期需要它：Adam 二阶矩估计需要几百步才可信）。
- **误区三**："decay 到 10% 就停了"——Chinchilla 的 10% 是 cosine 语境；WSD 语境下 decay 段应走得更低，否则"退火不充分"，最终 loss 明显偏高。

## ex

**练习 1（对应退出标准 1）**
从 SGD 理论说明为什么学习率必须衰减？constant 学习率下 loss 会停在哪里？

%%%

**参考答案：**
SGD 的迭代 = 梯度期望 + 与 \(\eta\) 成正比的噪声。loss 接近最优时梯度变小，但噪声半径不缩小，参数在半径 \(\propto\eta\) 的球里持续随机游走，loss 停在由学习率决定的平台上。衰减 \(\eta\) 逐步收缩游走球，参数才能沉到谷底。理论最优（强凸）为 \(\eta_t \propto 1/t\)；非凸实践解是"高位探索 + 末段快速收缩"。

**练习 2（对应退出标准 2）**
写出 linear、cosine、WSD 三种调度的公式，并说明 cosine 相比 linear 的改进在哪。

%%%

**参考答案：**
Linear：\(\eta_t = \eta_{\max}(1-t)+\eta_{\min}t\)，前段几乎不降、末段线性下沉。Cosine：\(\eta_t = \eta_{\min}+\frac{1}{2}\eta_{\max}(1+\cos\frac{\pi t}{T})\)，两头慢、中段快——把最陡的下降放在 loss 下降最快的中段，刀刃用在刀刃上。WSD：warmup 爬升 → 稳定期峰值 → 末段 5~10% 快速衰减，换来随时可停与可复用 decay。

**练习 3（对应退出标准 3）**
WSD 的三个工程红利是什么？各自的机制解释是什么？

%%%

**参考答案：**
① 随时可停：decay 段等价于对稳定期 checkpoints 的隐式平均（Hägele 2024），任何稳定期 checkpoint 接一段 decay 都接近全程最优；② decay 可复用（hitchhiker，Wiles 2025）：从稳定期 checkpoint 用小算力续 decay，搭车获得接近全衰减的 loss；③ 中期不怕"loss 平了"：稳定期平台是探索期的正常现象。机制核心：decay = 退火 = 把探索成果固化进参数。

**练习 4（对应退出标准 4）**
decay 段多长合适？cosine 与 WSD 各自的末值怎么设？

%%%

**参考答案：**
decay 占全程 5%~10% 收益最佳，低于 2% 固化不充分（MiniCPM 及后续工作报告）。末值：cosine 语境常用峰值 10%（Chinchilla）；WSD 语境 decay 末端应更低，1%~3% 甚至归零，否则"退火不充分"最终 loss 明显偏高。

**练习 5（对应退出标准 5）**
为什么真实大训练常在后期"拉大 batch + 衰减学习率"？这和临界 batch size 什么关系？

%%%

**参考答案：**
超过临界 batch size（2-4）后单纯加 batch 收益锐减，但缩放律研究（Muennighoff 2023 等）表明训练后期放大 batch 并同步衰减学习率比恒定 batch 更省算力——大步长 + 低学习率的组合在末段更高效。结果就是三段式配方：warmup → 稳定期（batch 可增长）→ decay（batch 达峰、学习率归零）。

**练习 6（对应退出标准 6）**
列出学习率调度的三个常见误区并说明为什么错。

%%%

**参考答案：**
① "cosine 一定优于 constant"：短训练/小步数实验下差别不大，constant 调试更方便，结论需千步以上真实训练才稳健；② "warmup 越长越稳"：超过 2%~5% 步数是浪费预算，几百到几千步即可（Adam 二阶矩需要时间累积）；③ "decay 到 10% 就停"：那是 cosine 语境，WSD 的 decay 应更低（1%~3% 或归零），否则固化不充分。

**练习 7（对应退出标准 7）**
设随机梯度 \(g_t=\nabla f(x_t)+\xi_t\)，\(\mathbb E[\xi_t]=0\)，\(\mathbb E[\lVert\xi_t\rVert^2]=\sigma^2\)，目标 \(L\)-光滑、\(\mu\)-强凸。
(a) 把 \(g_t\) 代入下降引理并取期望，推导出 \(\mathbb E[f(x_{t+1})]\le f(x_t)-\eta(1-\tfrac{L\eta}{2})\lVert\nabla f\rVert^2+\tfrac{L\eta^2}{2}\sigma^2\)。
(b) 令两项平衡，求出"平台"处的 \(\lVert\nabla f\rVert^2\)，再用 \(f-f^*\le\frac{1}{2\mu}\lVert\nabla f\rVert^2\) 给出平台高度关于 \(\eta\)、\(\kappa\)、\(\sigma^2\) 的表达式。
(c) 若把 batch 加大到原来的 \(B\) 倍（独立同分布采样），方差变为多少？由此说明为什么"降 \(\eta\)"与"加 batch"是同一个式子里的等价旋钮。
(d) 平台公式如何解释"WSD 的 decay 末端要走得比 10% 峰值更低"？

%%%

**参考答案：**
(a) 取 \(\Delta=-\eta g_t\) 代入 \(f(x+\Delta)\le f(x)+\langle\nabla f,\Delta\rangle+\frac L2\lVert\Delta\rVert^2\) 后取期望，用 \(\mathbb E[\langle\nabla f,g_t\rangle]=\lVert\nabla f\rVert^2\) 与 \(\mathbb E[\lVert g_t\rVert^2]=\lVert\nabla f\rVert^2+\sigma^2\) 即得。
(b) 两项平衡：\(\eta(1-\frac{L\eta}{2})\lVert\nabla f\rVert^2=\frac{L\eta^2}{2}\sigma^2\Rightarrow \lVert\nabla f\rVert^2_{\text{floor}}=\frac{L\eta\sigma^2/2}{1-L\eta/2}\approx\frac{L\eta\sigma^2}{2}\)。代入强凸不等式得 \(f-f^*\approx\frac{L\sigma^2}{4\mu}\eta=\frac{\kappa\sigma^2}{4}\eta\) —— **平台高度正比于 \(\eta\)**，降一个量级的平台就得降一个量级的 \(\eta\)。
(c) 对 \(B\) 个 i.i.d. 样本求平均，方差按样本数平均缩小：\(\operatorname{Var}(g_B)=\sigma^2/B\)。代入平台公式后平台高度 \(\propto \sigma^2\eta\) 也随之除以 \(B\) ⇒ 降低 \(\eta\) 与增大 batch 在同一式中可以互相替代——这就是训练末期同时"拉大 batch + 降学习率"的理论依据（两者是一旋钮的两面）。
(d) 平台高度 \(\propto\eta\)，所以末值越高、残留的平台越高、loss 越压不下去。WSD 的 decay 若停在峰值 10%，就还留着约 10% 的平台残留；衰减到 1%~3% 甚至趋零，才能把这条波动带收窄到几乎消失，真正"固化"到谷底。
