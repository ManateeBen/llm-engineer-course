## why

前三个阶段的课都在造零件：1-0 造了注意力（softmax(QKᵀ/√d)V）、2-0 造了残差连接、2-1 造了归一化层、2-2 造了位置编码。本单元干最后一件事：**把零件装成整机**，并且回答比"怎么装"更重要的问题——**每个部件为什么必须存在**。只背架构图的人，换个变体（阶段 3 后面的 MQA/MoE）就懵了；理解设计动机的人，看任何新论文都能先问"它改了哪个部件、缓解了什么矛盾"。学完本单元，你能对着任意一个 Transformer 变体的架构图，逐块说出它的设计理由；能手工算一遍一个 124M 模型的参数账本，知道"参数都花在哪"。

## body

### 整机一图

一个 Decoder-only Transformer（GPT 家族）的数据流，从上到下：

```
token id 序列
   │
   ▼
词嵌入查表 E（vocab × d）──────────────┐
   │                                   │ 权重共享（tied）
   ▼                                   │
+ 位置编码（RoPE 施加在 Q/K 上）        │
   │                                   │
   ▼                                   │
┌─ N × Transformer Block ──────────┐   │
│ LN → 多头因果注意力 → + 残差      │   │
│ LN → FFN（d→4d→d）→ + 残差        │   │
└──────────────────────────────────┘   │
   │                                   │
   ▼                                   │
final LN                                │
   │                                   │
   ▼                                   │
lm_head（d × vocab 线性层）◄───────────┘
   │
   ▼
logits（vocab 个数）→ softmax → 下一词分布
```

三个细节先记住，后面逐个讲动机：**位置编码不单独加一份**（RoPE 方案下它融进注意力的 Q/K）；**lm_head 与词嵌入共享权重**（不是所有模型都共享，但 GPT-2/LLaMA 共享）；**每个 Block 里 LN 在最前面**（Pre-Norm，3-2 专门讲为什么）。

### 部件一：Q/K/V 投影——为什么不能直接用 x

1-0 讲过注意力的公式 \(\text{softmax}(QK^\top/\sqrt d)V\)。第一个设计问题是：为什么不直接用隐藏状态 \(x\) 同时充当 Q、K、V？因为这三者在演不同的角色：

- **Query** 是"我在找什么"——一个查询向量，决定当前 token 关注谁；
- **Key** 是"我是什么"——被检索的索引，要和 Query 点积匹配；
- **V** 是"我贡献什么"——真正被加权求和搬走的信息。

同一个 \(x\) 要同时当好查询、索引和内容，三种目标会互相拉扯。三个独立投影矩阵 \(W_Q,W_K,W_V\)（各 \(d\times d\)）让每种角色有专门的表示空间。参数量代价：\(3d^2\) 每层每头组——这是"用参数换表达自由"的标准交易。

### 部件二：除以 \(\sqrt d\)——防止 softmax 饱和

1-0 讲过动机：\(q\cdot k\) 的方差随维度 \(d\) 线性增长，\(d=1024\) 时点典型值 ±32，softmax 被推到 one-hot，梯度趋零。\(\sqrt d\) 把方差压回 1 附近。这里补一个整机视角的观察：**这个缩放只在"点积未归一化"时必要**。有些变体（如对 Q/K 做 LayerNorm 或余弦相似度注意力）从根上去掉了大方差，就不再需要 \(\sqrt d\)——理解动机比记住除法更重要。

### 部件三：多头——把表示空间切成多个子空间

与其在完整的 \(d\) 维空间做一次注意力，不如切成 \(h\) 个头，每个头在 \(d/h\) 维的子空间独立做注意力，最后拼接再投影：

\[
\text{MultiHead}(x)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W_O,\quad \text{head}_i=\text{softmax}\!\left(\frac{Q_iK_i^\top}{\sqrt{d/h}}\right)V_i
\]

设计动机有三层：

1. **不同的头学不同的关系**：实证研究发现有的头盯相邻词（句法）、有的头盯相同词（共指）、有的头盯句法树深度——一个软注意力算不出这么多模式，多个子空间各司其职。
2. **每头的 \(\sqrt{d/h}\) 缩放**：注意缩放是按头维度算的，切头后每头的点积方差回到 \(d/h\) 的量级，正好。
3. **参数几乎不变**：切头后总计算量与单头全维度基本相同（都是 \(d^2\) 级别的投影），等于免费获得表示多样性。

代价：头数 \(h\) 是超参。太小（如 1）丢失多样性，太大（如 128）每头维度 \(d/h\) 太窄、单头学不动。常见配比 \(d/h\in[64,128]\)。

### 部件四：FFN——注意力之外的非线性与记忆

每个 Block 的第二个子层是位置-wise FFN（对每个 token 独立作用）：

\[
\text{FFN}(x)=\sigma(xW_1+b_1)W_2+b_2,\quad W_1:d\to 4d,\ W_2:4d\to d
\]

设计动机：

1. **非线性**：注意力本身是线性变换的加权组合（softmax 权重 × V 的求和），没有非线性激活；FFN 是 Block 里唯一的逐点非线性来源。
2. **参数主力**：FFN 占了每层约 \(2/3\) 的参数（\(8d^2\) vs 注意力的 \(4d^2\)）。"模型的知识主要存在 FFN 里"是后来可解释性研究的共识（阶段 8 的探针实验会验证这一点）。
3. **4 倍扩张再压回**：先升到 \(4d\) 维再投影回来，等于给每个 token 一个高维"思考空间"。为什么是 4？经验值，Swigu 等激活函数出现后部分模型改窄一些（如 \(\frac{8}{3}d\)），但量级不变。
4. **激活函数的选择**：GPT-2 用 GELU，LLaMA 用 SwiGLU（把 Swish 门控引入 FFN，\(\text{SwiGLU}(x)=\text{Swish}(xW_1)\odot (xW_3)\) 再投回）——门控给 FFN 一个"筛掉不重要特征"的机制，同规模下略优，代价是多一个投影矩阵。

### 部件五：残差 + 归一化——让 100 层可训练

2-0 讲了残差的梯度通路，2-1 讲了归一化的方差修正。整机视角的记忆法：**残差提供"恒等高速公路"，归一化提供"每层出口的标定"**，两者缺一不可——只有残差没有归一化，深网的激活尺度会漂移（2-1 的病）；只有归一化没有残差，梯度照样指数衰减（2-0 的病）。现代 LLM 的配方是 Pre-LN + 残差 + final norm（3-2 专门展开）。

### 部件六：causal mask——自回归的代价结构

Decoder 的注意力矩阵上三角被置为 \(-\infty\)（softmax 后为 0）：位置 \(i\) 只能看 \(\le i\) 的位置。为什么？训练时整段文本一次前向、每步都做下一个词预测（0-8 的训练目标），如果不 mask，模型能"偷看答案"——第 \(i\) 个位置的预测直接看到第 \(i+1\) 个词，loss 会虚假地低。**causal mask 不是架构选择，是诚实性要求**：它保证每个位置的预测只依赖过去，与生成时的真实信息条件一致。

代价：注意力矩阵一半是浪费的。3-7 的一些新架构（线性注意力/SSM）正是在这个代价结构上做文章。

### 部件七：lm_head 与权重共享

最后一层线性投影 \(d\to\text{vocab}\) 把隐藏状态变成词表上的 logits。一个常见选择是**让它和词嵌入矩阵共享权重**（tied embeddings，Press & Wolf 2017 发现共享通常不损甚至略升质量，还省参数）。动机：嵌入矩阵回答"每个词的向量是什么"，lm_head 回答"这个向量最像哪个词"——两个问题互为转置，共享让模型维持这种对偶。GPT-2/LLaMA 共享；有些大模型（如部分多语言模型）不共享，因为词表极大时嵌入矩阵本身就是参数大户。

### 参数账本：124M 的 GPT-2 small 花在哪

以 \(L=12, d=768, \text{vocab}=50257\) 为例（GPT-2 small 实际 124M）：

| 部件 | 公式 | 参数量 | 占比 |
|---|---|---|---|
| 词嵌入 + lm_head（共享） | \(\text{vocab}\times d\) | 38.6M | 31% |
| 每 Block 位置-wise FFN | \(2\times d\times 4d=8d^2\) | 4.7M × 12 = 56.6M | 46% |
| 每 Block 注意力投影 | \(4d^2\)（Q/K/V/O） | 2.4M × 12 = 28.7M | 23% |
| 每 Block LN | \(2\times 2d\) | 0.05M | ~0% |

两个立刻能用上的结论：**词嵌入占了近 1/3**（所以词表大小直接吃参数，3-6 的词表设计是架构决策的一部分）；**FFN 是参数主力**（占近一半，所以 MoE（3-4）几乎总是把专家做在 FFN 上——把最大的那块切成条件计算最划算）。层数加深 2 倍参数只增约 2 倍，但计算量也增约 2 倍——这是 2-3 缩放律里 N 的口径。

以 \(n\) 个 token、批大小 \(b\) 为例（形状是本单元的检查清单）：

| 阶段 | 形状 |
|---|---|
| 输入 token id | \((b, n)\) |
| 词嵌入 | \((b, n, d)\) |

## ex

**练习 1（对应退出标准 1）**
为什么注意力用三个独立投影 \(W_Q,W_K,W_V\) 而不是直接用隐藏状态 \(x\)？用"角色"语言回答。

%%%

**参考答案：**
Q/K/V 在演三个不同角色：Query 是"我在找什么"（查询），Key 是"我是什么"（被匹配的索引），V 是"我贡献什么"（被搬走的内容）。同一个 \(x\) 兼任三角色会互相拉扯；独立投影让每种角色有专门的表示空间，代价是每层多 \(3d^2\) 参数——用参数换表达自由。

**练习 2（对应退出标准 2）**
一个 Decoder-only 模型 \(L=24, d=1024, \text{vocab}=32k\)，嵌入与 lm_head 共享权重。估算总参数量，并指出哪两个部件占大头。

%%%

**参考答案：**
嵌入（共享）\(32k\times1024=32.8M\)；每 Block：注意力 \(4d^2=4.2M\) + FFN \(8d^2=8.4M\) = 12.6M，×24 = 302M；合计约 335M（未计 LN 与偏置）。大头：FFN（202M，约 60%）与嵌入（33M，约 10%）——FFN 是参数主力，所以 MoE 总把专家做在 FFN 上。

**练习 3（对应退出标准 3）**
causal mask 具体在注意力分数矩阵上怎么操作？如果不加 mask，训练 loss 会发生什么？为什么这与"下一个词预测"目标不自洽？

%%%

**参考答案：**
在 softmax 之前把分数矩阵的上三角（\(j>i\) 的位置）置为 \(-\infty\)，softmax 后这些位置权重为 0，位置 \(i\) 只能看到 \(\le i\) 的位置。不加 mask 时第 \(i\) 个位置的预测能直接看到第 \(i+1\) 个词（即答案），loss 虚假地低；而生成时模型并没有未来信息，训练与推理的信息条件不一致——mask 是保证两者一致的诚实性要求。

**练习 4（对应退出标准 4）**
FFN 的"先升到 \(4d\) 再压回"在计算上意味着什么？为什么 MoE 几乎总把专家放在 FFN 而不是注意力上？

%%%

**参考答案：**
升维给每个 token 一个 \(4d\) 的高维非线性变换空间，压回保持残差流维度不变；代价是中间激活显存 \(\propto n\cdot 4d\)。MoE 把专家放 FFN，因为 FFN 占每层约 2/3 参数且是逐 token 独立的（无需跨 token 通信），切成"每 token 只激活少数专家"的稀疏结构最自然、通信与实现代价最低。

**练习 5（对应退出标准 5）**
列出从 token id 到下一词分布的完整数据流，并说出每一步的形状变化（设 \(b=2,n=16,d=768,\text{vocab}=50k\)）。

%%%

**参考答案：**
token id \((2,16)\) → 嵌入 \((2,16,768)\) → 位置信息融入 Q/K → 每 Block：LN → 注意力（分数表 \((2,h,16,16)\)，mask 上三角）→ 残差相加 → LN → FFN（中间 \((2,16,3072)\)）→ 残差相加 → final LN → lm_head \((2,16,50257)\) → softmax 得分布。训练时取每个位置预测下一个词的 NLL 求平均（0-8 的目标）。
